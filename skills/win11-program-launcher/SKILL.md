# Win11 程序启动器

此技能帮助 Windows 11 用户通过**批处理脚本 (.bat)** 一键启动或批量启动程序，以及强制关闭程序。

---

## 适用场景

- 需要在 Win11 上写一个批处理脚本来启动一个或多个程序
- 需要一键同时启动多个程序（如录屏工具、辅助工具等）
- 需要一键强制关闭指定的程序
- 制作"演示/录屏/开发环境"的一键启停脚本

---

## 核心语法

### 1. 启动程序

```batch
start /d "程序的所在目录完整路径" 程序名.exe
```

- `start` — 启动一个新窗口运行程序
- `/d` — 指定程序的**起始工作目录**（程序运行时的当前目录）
- 后面跟要执行的 `.exe` 文件名

**注意：** 如果程序路径不在系统 PATH 中，务必使用 `/d` 指定目录，否则可能找不到依赖文件。

### 2. 强制关闭程序

```batch
taskkill /f /im 程序名.exe
```

- `taskkill` — 结束进程
- `/f` — 强制终止（不等待程序响应）
- `/im` — 按镜像名（即进程名）匹配

---

## 完整示例：一键启停多个程序

以下是一个真实的"录制演示视频辅助工具"脚本，先启动三个工具，再用下半部分一键全部关闭：

```batch
@echo off
chcp 65001 >nul

:: ====== 启动程序 ======
start /d "D:\software\PointerFocus\pointerfocus2.4\PointerFocus" PointerFocus.exe
start /d "C:\Users\Administrator\AppData\Local\carnac" Carnac.exe
start /d "D:\software\obs\obs-studio\bin\64bit" obs64.exe

echo 所有程序已启动！
pause

:: ====== 关闭程序 ======
taskkill /f /im obs64.exe
taskkill /f /im PointerFocus.exe
taskkill /f /im Carnac.exe

echo 所有程序已关闭！
pause
```

> `@echo off` 关闭命令回显，`chcp 65001 >nul` 设置控制台编码为 UTF-8 防止中文乱码，`pause` 让窗口停留等待按键。

---

## 生成脚本的原则

为 Win11 用户生成脚本时，遵循以下原则：

1. **始终以 `@echo off` 开头**，保持输出干净
2. **添加 `chcp 65001 >nul`** 防止中文乱码
3. **路径用双引号包裹**，防止空格路径出错
4. **启动和关闭分成两个区域**，用 `::` 注释分隔
5. **后缀使用 `.bat`**（兼容性最好，Win11 直接双击运行）
6. **如果不确定某个程序所在目录**，可以建议用户用 Win11 任务管理器的"打开文件所在位置"来定位
7. **关闭脚本永远放在同一个文件的后面**，用 `pause` 隔开，方便用户先启动、用完后一键关闭

---

## 与用户交互

当用户请求"启动程序"或"批量启动"时：
1. 先问清要启动哪些程序、各自的安装路径
2. 如果用户只提供程序名不知道路径，可以建议几种定位路径的方法：
   - 开始菜单 → 右键程序 → 打开文件位置
   - 任务管理器 → 找到进程 → 右键 → 打开文件所在位置
   - `where 程序名` 命令（仅对 PATH 中的程序有效）
3. 生成 `.bat` 脚本给用户，放在一个方便的位置（如桌面或项目目录）
4. 提醒用户：双击 `.bat` 即可运行，右键可"以管理员身份运行"（某些程序需要管理员权限）
