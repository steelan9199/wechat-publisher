# 让人一眼看呆的三维数学图形 · 公式清单

> 下面每一项都是**一个公式**画出的三维实体。按"震撼程度"分四类。

---

## Ⅰ 极小曲面与周期结构

### 1. Gyroid（旋节面 / Schwarz P 曲面）★★★★★
```
cos x·cos y + cos y·cos z + cos z·cos x = 0
```
三个余弦的和等于零。**没有任何参数、没有一张图**，却能沿三个方向无限重复 tiling 而无缝。
它是"三周期极小曲面"里唯一被实际使用的一种——建筑镂空、3D 打印支撑、光学镂空结构都在用。
> 极小曲面 = 平均曲率为零 = 肥皂泡的最小自然形态。

### 2. Schwarz D 曲面 ★★★★
```
2cos x·cos y·cos z − cos²x − cos²y − cos²z + 1 = 0
```
同家族的另一张三周期极小曲面，长相完全不同：像不断自我穿插的编织骨架。

### 3. Enneper 曲面 ★★★★
```
x = u − u³/3 + uv²
y = v − v³/3 + u²v
z = u² − v²
```
方程短到能背下来。中央有一个**无法消去的奇点**，曲面在那里自己穿过自己，像被拧麻花的号角。

### 4. 螺旋面 Helicoid ★★★
```
r = a·θ（绕 z 轴螺旋上升）
```
和悬链面一起，是仅有两种"能用一张纸做出来"却仍然保持极小的曲面。

## Ⅱ 拓扑怪胎（真正的数学奇观）

### 5. 克莱因瓶 Klein Bottle ★★★★★
```
x = (a + cos(u/2)sin v − sin(u/2)sin 2v)·cos u
y = (a + cos(u/2)sin v − sin(u/2)sin 2v)·sin u
z = sin(u/2)sin v + cos(u/2)sin 2v
```
**只有一个面**：瓶口和瓶底相连，曲面从内侧穿出去又从外侧穿回来。
三维空间里造不出来，只能在四维空间里理解。绝大多数人第一次看都会以为哪里画错了。

### 5b. 克莱因瓶（瓶形 / 带把手）★★★★★
```
x = −(2/15)·cos u·(3cos v − 30sin u + 90cos⁴u sin u − 60cos⁶u sin u + 5cos u cos v sin u)
y = −(1/15)·sin u·(3cos v − 3cos²u cos v − 48cos⁴u cos v + 48cos⁶u cos v − 60sin u
                     + 5cos u cos v sin u − 5cos³u cos v sin u − 80cos⁵u cos v sin u
                     + 80cos⁷u cos v sin u)
z = (2/15)·(3 + 5cos u sin u)·sin v
```
**同一个克莱因瓶，第二种画法。** 上面那条是"**8 字形浸入**"，长成一根扭转的环管，像加粗的莫比乌斯管；
这一条是"**瓶形浸入**"——大众印象里那个**带把手的瓶子**：瓶颈弯下来、穿过瓶身、再连回瓶底。
两者拓扑完全相同（不必剪开就能互相变形），区别只在于嵌入三维空间的方式。
> 用哪个：要"一眼认出是克莱因瓶" → 用瓶形；要直观展示"单面 / 自交" → 8 字形也行。

### 6. 莫比乌斯带 Möbius Strip ★★★★★
```
x = (R + v·cos(u/2))·cos u
y = (R + v·cos(u/2))·sin u
z = v·sin(u/2)
```
只有**一条边**。跟着边走一圈会回到出发点的反面。传送带、剪纸环都源于此。

### 7. 博伊曲面 Boy's Surface ★★★★
```
x = cos(u/2)cos v − sin(u/2)sin 2v
y = cos(u/2)sin v + sin(u/2)cos 2v
z = 2sin(u/2)
```
真实空间里"单面"的最佳代表，是**射影平面**在三维的浸没。

### 8. 罗马曲面 Roman / Steiner ★★★
```
x = sin t·cos²u
y = sin t·sin u·cos u
z = cos t + ½(cos 2t − 1) + ½(cos 2t − 2cos²u)
```
带三重对称和自交点，投影像一朵金属花。

### 9. 加百列号角 Gabriel's Horn ★★★
```
y = 1/x（绕 x 轴旋转）
```
**有限体积装下无限长曲线**：尾巴永远粗、永远填不满，却能塞进有限空间。
著名的"加百列号角悖论"。

## Ⅲ 分形（无限细节）

### 10. 曼德球 Mandelbulb（8 次方）★★★★★
```
r = |z|,  θ = acos(z_z / r),  φ = atan2(z_y, z_x)
z ← r⁸ · ( sin 8θ cos 8φ,  sin 8θ sin 8φ,  cos 8θ ) + c
```
把曼德布罗集合升到三维、指数改成 8。注意这里的"z⁸"是**球坐标下的幂映射**，
不是复数乘法 —— 三角函数的角都要乘以 8，这才是三维曼德球。
整个球体由无数小球长出来，表面褶皱在任何缩放下都重复出现。
分形最震撼的三维代表。

### 11. 门格海绵 Menger Sponge ★★★★
```
立方体均分 27 块 → 挖掉中心 + 6 个面中央 → 对剩余每块重复
等价判据：点的三进制展开里，每一层至多一个坐标的数字为 1
```
**体积趋于 0，表面积趋于无穷**——一个"无限大却没重量"的物体。
（"逐层挖 7 块"用全局坐标写时容易写错：对坐标对加约束、却放开第三个轴，
挖到的是贯穿整条轴的长条板，第 2 层起就全部失效。本画廊渲 3 层。）

### 12. 超公式 Superformula（Gielis）★★★★★
```
r(φ) = ( |cos(mφ/4)/a|^n₂ + |sin(mφ/4)/b|^n₃ )^(−1/n₁)
```
一个公式描述几乎所有形状：换 m, n 就从五角星变成贝壳、变成花朵、变成球。
本图取 m=6 并绕轴拉伸，得到一朵六瓣的**立体星**。

### 13. 阿波罗尼斯球夹 ★★★
```
反复对球做反演 |z| ↦ 1/conj(z − c)
```
从五个相切球出发不断反演，缝隙里生出无穷多小球。数学里最密集的三维分形之一。

### 17. 三叶结 Trefoil Knot ★★★★
```
x = (1 + 0.42cos3u)cos2u
y = (1 + 0.42cos3u)sin2u
z = 0.55sin3u
```
(p,q)=(2,3) 的环面结。它和圆环一样闭合，但绳头永远抽不出来——
拓扑学里"本质不同"的第一条证据。

## Ⅳ 混沌与吸引子

### 14. 洛伦兹吸引子 ★★★★★
```
ẋ = σ(y − x)
ẏ = x(ρ − z) − y
ż = xy − βz      (σ=10, ρ=28, β=8/3)
```
蝴蝶形状。**初始值只改百万分之一，轨迹就完全分道扬镳**——蝴蝶效应的源头。

### 15. de Jong 吸引子 ★★★★
```
x' = sin(a·y) − cos(b·x)
y' = sin(c·x) − cos(d·y)
```
只靠两个 sin/cos，长出像神经丛一样的三维云。

### 16. 克利福德吸引子 ★★★★
```
x' = sin(a·y) + c·cos(a·x)
y' = sin(b·x) + d·cos(b·y)
z' = sin(c·x) + d·cos(c·z)
```

### 16. 原子轨道（d 轨道 / f 轨道）★★★★★
```
|Y_lm(θ,φ)| = c    （球坐标下的实球谐函数等值面，再与球 r<R 求交）
```
量子力学里电子的"轨道"不是路径，而是**概率的等值面**。

| 轨道 | Y_lm | c | R | 瓣数 |
|---|---|---|---|---|
| d（l=2, m=0） | `3cos²θ − 1` | 0.62 | 0.90 | 4 |
| f（l=3, m=0） | `cosθ(5cos²θ − 3)` | **0.50** | 0.96 | 5 |

> ⚠️ **2026-10-05 订正**：原文写「f 轨道取 c=0.95」是**错的**。
> `Y₃₀ = cos3θ` 的上界只有 1.0，`|cos3θ| > 0.95` 只剩极值附近，
> 填充率仅 2.07%，渲出来塌成两片碎块。`c=0.50` 后填充率 5.23%，恢复 5 瓣。
> **阈值必须相对场的实际上界来设**，而 `|Y_lm|` 的上界随 l 变化
> （`Y₂₀` 上界 2.0，故 d 轨道 `c=0.62` 合理）。
>
> ⚠️ **2026-10-05 订正**：原文写「视线必须垂直于 z 轴」也是**错的**。
> 俯视（elev≈74）会让两瓣重叠成饼，**`elev=35` 才能让瓣清晰分离**。
>
> 关键细节：单纯取极锥区域在拓扑上只有**一个连通帽**，看不出多瓣；
> 必须让视线与 z 轴成约 35° 夹角，瓣才会分离成经典形状。
