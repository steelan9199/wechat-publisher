# ICO 图标设计法则库

本文件是 `ico-prompt-master` 技能的核心知识库。内容来自对 9 个顶级图标(微信、WorkBuddy、豆包、Trae、Apple、Google、Microsoft、Edge、Chrome)的逐个解剖与共性提炼，并补充 ICO 文件图标的硬约束。

---

## 一、9 大图标逐个解剖

### 1. 微信 (WeChat)
- **容器**：圆角方形(早期)→ 现多为纯符号无外框
- **主体**：双对话气泡(一大一小，小气泡叠在大气泡右下)，两个气泡内各一个圆点(眼睛)
- **色彩**：主色微信绿(#07C160)，气泡白底绿描边或绿底白描边
- **质感**：扁平 + 极轻微渐变(提升层次但不抢戏)
- **法则提炼**：亲和力优先；具象语义(对话=通讯)；双色克制；圆润无锐角

### 2. WorkBuddy
- **容器**：圆角 squircle 容器，品牌色底
- **主体**：字母 "W" 居中，几何化处理
- **色彩**：品牌主色容器 + 对比色字母
- **质感**：扁平微渐变，容器有轻微立体感
- **法则提炼**：字母 logo 派；容器+字母双层次；品牌色统一识别

### 3. 豆包 (Doubao)
- **容器**：圆角方形或正圆，圆润饱满
- **主体**：萌系具象(豆子/小精灵)，大眼圆润
- **色彩**：粉/紫/暖色渐变，柔和明快
- **质感**：柔和渐变 + 微拟物(轻微高光)
- **法则提炼**：萌系亲和；暖色渐变；圆润饱满无锐角；情绪化表达

### 4. Trae
- **容器**：圆角 squircle
- **主体**：抽象几何字母/符号，科技感切割
- **色彩**：双色对比(深底亮字 或 互补色)
- **质感**：扁平或微渐变，锐利边缘
- **法则提炼**：科技几何；字母派；双色高对比；锐利无圆滑

### 5. Apple
- **容器**：macOS 应用图标用 squircle(超椭圆)容器；品牌 logo 为纯符号无容器
- **主体**：被咬一口的苹果剪影
- **色彩**：品牌 logo 经典银/灰/黑单色；应用图标用主题色渐变
- **质感**：应用图标——squircle 容器 + 主体渐变 + 大留白；logo——纯色扁平
- **法则提炼**：极致剪影辨识度；squircle 黄金容器；大留白；单色可逆(深浅模式适配)

### 6. Google
- **容器**：Material Design 应用图标多无外框(纯符号)；品牌 logo 无容器
- **主体**：应用图标=几何拼接的抽象符号；品牌 logo=多色字母 G
- **色彩**：每个 app 一个主色 + 白色符号；品牌 logo=蓝红黄绿四色
- **质感**：纯扁平，无渐变无阴影(Material 风格)
- **法则提炼**：扁平至上；单色主色策略；几何拼接；无装饰

### 7. Microsoft (Fluent)
- **容器**：圆角 squircle(Windows 11 起)
- **主体**：抽象几何图形，常带等距透视(isometric)感
- **色彩**：1 主色 + 中性灰，多色块组合(如 Office 四色块)
- **质感**：微渐变 + 轻微透视立体感(Fluent Design)
- **法则提炼**：几何+透视；多色块分层；微渐变层次；专业稳重

### 8. Edge 浏览器
- **容器**：圆角 squircle(Microsoft 风)或无容器
- **主体**：波浪 swoosh 曲线(形似海浪/字母 e 的抽象)
- **色彩**：蓝→青→绿的多色对角渐变
- **质感**：丰富渐变 + 微光，动感流动
- **法则提炼**：渐变现代派代表；曲线动感；多色对角渐变；流动光感

### 9. Chrome 浏览器
- **容器**：正圆
- **主体**：三色环(红黄绿)包裹中心蓝色圆
- **色彩**：三原色环 + 中心蓝，高饱和但克制
- **质感**：扁平 + 极轻渐变(近年趋扁平)
- **法则提炼**：字母/容器圆环派；三色环构图；中心焦点；高辨识几何

## 二、9 大共性法则(所有顶级图标共守)

1. **容器化**：绝大多数有一个统一容器(圆角 squircle / 正圆 / 盾形)承载内容，保证图标群组排列整齐。纯符号派(Google/Apple logo)是例外，但应用图标仍回归容器。
2. **单一视觉焦点**：一个核心符号/字母/具象物，绝不堆砌多元素。多元素时必有一个主次关系(如 Chrome 三色环围绕中心蓝圆)。
3. **几何简化**：曲线/直线锚点极少，形体能用基本几何(圆、圆角矩形、三角)拆解。复杂度越低，缩放越稳。
4. **剪影可辨识(Silhouette Test)**：纯黑剪影下仍能认出是什么。缩到 16×16 像素仍不糊——这是 ICO 文件图标的生死线。
5. **限定色板**：1-3 个主色 + 中性色。色相不超 3 个，饱和度克制(除非刻意鲜艳如游戏类)。
6. **渐变方向统一**：用渐变时方向一致(多取左上→右下 或 对角)，营造立体但不浮夸。避免放射状混乱渐变。
7. **安全留白**：主体占容器约 70-80%，四周留 10-15% 呼吸空间。主体绝不贴边。
8. **边缘锐利**：矢量描边，边缘干净。除特定氛围图标外，无模糊光晕、无羽化。
9. **平台适配**：可去背景透明、可单色化(适配深色模式)、可缩放多尺寸(16/32/48/64/128/256)。

## 三、三大流派细化法则

### 流派 A：极简几何派
**代表**：Google Material / Microsoft Fluent / Apple / Trae
- 容器：squircle 或无容器
- 主体：字母 / 抽象几何符号
- 色彩：单色扁平 或 1 主色+中性
- 质感：纯扁平 或 微渐变(Microsoft/Apple)
- **正面案例**：Google Drive(三角几何+绿)、Apple Mail(信封+蓝渐变)、Microsoft Word(蓝底白W)
- **反面案例**：给极简派加拟物高光、加材质纹理——立刻掉档
- **提示词关键词**：flat design, geometric, minimal, single focal point, vector, sharp edges, limited palette, squircle container

### 流派 B：渐变现代派
**代表**：Edge / 豆包 / Trae(部分)
- 容器：圆角 squircle
- 主体：抽象曲线 / 萌系具象
- 色彩：多色对角渐变 / 暖色柔和渐变
- 质感：渐变 + 微光，可轻微拟物
- **正面案例**：Edge(蓝青绿 swoosh)、豆包(粉紫萌系)
- **反面案例**：渐变方向混乱、色块过碎成马赛克、渐变断层
- **提示词关键词**：gradient, modern, vibrant, diagonal gradient, smooth transition, glossy, rounded, soft glow

### 流派 C：社交亲和派
**代表**：微信
- 容器：圆角方形 或 纯符号
- 主体：对话气泡 / 圆润具象
- 色彩：亲和双色(绿+白 / 蓝+白)
- 质感：扁平 + 极轻渐变
- **正面案例**：微信(双气泡绿)、WhatsApp(电话+对话)
- **反面案例**：锐角、冷色、过于商务
- **提示词关键词**：friendly, rounded, approachable, speech bubble, warm colors, flat with subtle gradient

### 流派 D：字母容器派
**代表**：Chrome / WorkBuddy
- 容器：正圆 / 盾形 / squircle
- 主体：字母 logo 或 中心符号
- 色彩：多色环 / 品牌色容器
- 质感：扁平 或 渐变环
- **正面案例**：Chrome(三色环+蓝心)、WorkBuddy(W+品牌色)
- **反面案例**：字母字体随意(非几何化)、容器与字母色相冲突
- **提示词关键词**：lettermark, circular badge, brand color, centered, geometric letter, ring composition

## 四、ICO 文件图标硬约束(生图阶段必须遵守)

ICO 用于 Windows 文件/快捷方式/文件夹图标，与普通插画不同，有硬约束：

1. **正方形画布**：必须 1:1。推荐 1024×1024 或 2048×2048 生成，转 ico 时缩放多尺寸。
2. **主体居中 + 安全留白**：主体占画布 70-80%，四周留 10-15% 空白。Windows 显示图标时会自动加圆角/阴影，贴边会被裁。
3. **背景处理**：
   - 理想：纯透明背景(PNG with alpha)
   - 退而求其次：纯白背景(转 ico 时去白)
   - 禁止：复杂背景、渐变背景、场景背景——会与文件管理器叠加显得脏
4. **边缘锐利矢量感**：避免照片写实、避免柔焦光晕。缩小到 16px 时模糊边缘=图标报废。
5. **剪影测试**：提示词中要求「silhouette recognizable at 16px」。
6. **多尺寸友好**：避免细线条(缩 16px 消失)、避免小字(缩 16px 成糊)、避免高频细节。
7. **深浅模式兼容**：避免依赖纯黑或纯白背景，主体本身要有足够对比度。

## 五、提示词组装模板

按 `[主体] [容器] [色彩] [质感] [构图] [风格参考] [ICO约束]` 七段式组装：

```
[主体描述: 1个核心符号/字母/具象物],
[容器: 圆角squircle/正圆/无容器],
[色彩: 主色+辅色, 限定2-3色],
[质感: 扁平/微渐变/拟物, 渐变方向],
[构图: 居中, 主体占70-80%, 四周留白15%],
[风格参考: Material/Fluent/Edge/微信 风格],
[ICO约束: 正方形画布, 纯白/透明背景, 边缘锐利矢量感, 16px剪影可辨识]
```

现代 AI 绘图平台(即梦/豆包)趋向只用正向提示词，本技能不输出负向提示词。需要规避的元素一律转化为正向约束表达(如「单一主体、纯色背景、干净矢量边缘」)。
