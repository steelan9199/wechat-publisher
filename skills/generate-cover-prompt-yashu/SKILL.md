# 公众号封面提示词

## 核心理念

封面不是文章的装饰画，是文章核心内容一眼看懂的视觉翻译。读者在信息流里只给封面一秒钟，这一秒里封面必须讲完一个具体的故事，而故事必须来自这篇文章区别于同类文章的那个点。

方法分三步：找钩子、编故事、字面写。三条环环相扣，任何一步偷懒，封面就退化成一张和文章无关的漂亮图。

## 执行流程

### 第一步：读文章，找到核心钩子

如果用户给的是文件路径，先读文件再开始。如果用户只给了主题没有正文，基于主题合理设计，并在输出开头说明这是基于主题的假设。

读完全文后回答一个问题：这篇文章和同主题的其他文章比，最不一样、最想让读者记住的是什么？

- 科技教程文：往往是某个机制
- 观点热点文：往往是某个反差或冲突
- 生活情感文：往往是某个转变瞬间，如从内耗到松弛
- 盘点资源文：往往是数量多与获取轻松的爽感

不要停在主题领域和情绪调性这种泛化层面。钩子找错了，封面再好看也带不来点击。

### 第二步：把钩子翻译成两个不同的视觉故事

每个故事是一个具体场景，有主体、有动作、有关系。两条提示词必须讲不同的故事。

自检标准：把两条提示词的配色互换，画面依然成立但故事不同，才算合格。如果只是同一画面换两套颜色，重做第二条。

抽象概念必须翻译成可见物件，

想不出对应物件时，回第一步重新审视钩子，不要硬编一个空泛的画面。

### 第三步：按文章类型定配色基调

风格跟内容走，不是固定模板。以下为起点，按文章实际情绪微调，总主色不超过三种。

| 文章类型 | 背景 | 配色 | 质感与光 |
|---|---|---|---|
| 科技 / AI / 编程 | 深色渐变 | 蓝紫青 | 玻璃、霓虹描边、粒子光点、淡网格，冷调硬光高对比 |
| 生活 / 情感 / 治愈 | 浅色或暖色 | 低饱和暖色或马卡龙色 | 柔光低对比，背景轻微虚化 |
| 职场 / 商业 | 大色块 | 低饱和高级灰加一个点缀色 | 克制均匀光 |
| 知识 / 教程 / 工具 | 明亮浅色 | 青蓝加白 | 等距立体插画、清透高光 |
| 热点 / 观点 | 强对比 | 大胆双色 | 冲击力强的方向光 |

### 第四步：写提示词

一条提示词是一段流畅的中文自然语言，按固定顺序一气写完，不加分节标题：

画幅与风格的开头一句 → 主体（是什么、在什么位置、占多大画面）→ 主体之间的动作与连接关系 → 背景与点缀元素 → 光的方向与性质 → 配色归纳 → 收尾约束句。

硬规则，每条都有原因：

- 不用引号、书名号、括号包裹任何词。被包裹的词会被当成要画出来的文字渲染到图上。
- 不写十六进制色号，颜色一律用文字描述，如深蓝到紫的渐变。色号会被当文字画上去。
- 不写象征、寓意、暗示、代表。AI 不理解这些词，只会把字面词画出来。想表达什么就直接描述那个东西本身。
- 画幅与风格的开头句可以出现宽幅横版、插画、封面插画这类词，但公众号、信息流、高清、2K、分辨率等平台规格词绝不写进正文，比例信息只放提示词最后一行：图片比例：21:9
- 数量、位置、材质、光向全部写具体

### 第五步：给出AI生图平台

两条提示词之后附上AI生图平台信息列表，必须包含：

AI生图平台

1. 即梦 https://jimeng.jianying.com/ai-tool/home?activeTab=activity
2. 豆包 https://www.doubao.com/chat/
3. 公众号自带的AI配图

## 输出格式

先一句话说清文章的核心钩子，以及两个视觉故事分别讲什么。然后依次输出：

- 提示词一：故事名加一句话说明，提示词放代码块
- 提示词二：故事名加一句话说明，提示词放代码块
- 使用建议

## 反面清单

以下写法会产出坏图，出现任何一条就重写：

- 提示词里出现被引号包裹的词、色号、象征寓意类词
- 两条提示词只有颜色不同、故事相同
- 画面里安排了文字
- 只有情绪词没有具体物件，读完不知道图上到底有什么
