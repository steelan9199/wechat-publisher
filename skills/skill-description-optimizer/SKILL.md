# skill-description-optimizer

技能 Description 低级AI兼容性优化器

## 功能概述

本 Skill 专门优化 Skill 的 `description` 字段（frontmatter 中的 `description`），使其在低级AI（仅靠关键词匹配和模式识别来决策的AI）上也能被准确触发。

核心原理：**从"描述技能是什么"转为"告诉AI什么时候必须触发"**。

## 环境说明

- 本 Skill 为纯文本优化工具，不包含脚本/代码
- 操作对象：目标 Skill 的 `SKILL.md` 文件中的 frontmatter `description` 字段
- `$SKILL_DIR` = 目标 Skill 所在目录

---

## 触发映射：用户说 → AI 做

| 用户输入触发词                                          | AI 执行动作        |
| ------------------------------------------------------- | ------------------ |
| "优化 description" / "技能触发不了" / "AI 识别不到技能" | 按【优化流程】执行 |
| "description 有毛病" / "技能调用失败" / "低级AI用不了"  | 按【优化流程】执行 |
| "检查 description" / "评估 description"                 | 按【诊断流程】执行 |

---

## 核心法则：Description 五要素

一条优秀的、低级AI兼容的 `description` 必须包含以下五要素：

| #   | 要素             | 作用                     | 示例                                         |
| --- | ---------------- | ------------------------ | -------------------------------------------- |
| 1   | **触发关键词**   | 让低级AI靠关键词就能命中 | "扣子"、"coze"、"Coze"                       |
| 2   | **触发意图**     | 明确什么意图下必须触发   | "意图涉及调用智能体、触发工作流、测试智能体" |
| 3   | **常见用户表达** | 覆盖口语化/多样化说法    | "测试扣子智能体、调用扣子Bot、coze workflow" |
| 4   | **强制语气**     | 用"必须触发"替代"使用"   | "必须触发本技能" 而非 "可以使用"             |
| 5   | **否定约束**     | 排除误触发场景           | "不支持扣子编程平台"                         |

---

## 优化流程

| 步骤 | 执行动作             | 具体操作                                                                    |
| ---- | -------------------- | --------------------------------------------------------------------------- |
| 1    | 读取目标 description | 运行 `Read` 读取目标 Skill 的 `SKILL.md`，提取 frontmatter 中的 description |
| 2    | 逐要素诊断           | 对照【五要素】逐项检查，标记 ✅/❌                                          |
| 3    | 提取技能信息         | 从 SKILL.md 正文提取：功能、适用场景、用户可能的自然语言表达                |
| 4    | 重写 description     | 按【重写模板】生成新 description                                            |
| 5    | 对比展示             | 输出修改前/修改后对比，并说明每处改动的理由                                 |
| 6    | 写入文件             | 运行 `SearchReplace` 替换原 description                                     |

## 重写模板

```
当用户消息中出现"{关键词1}"、"{关键词2}"等关键词，且意图涉及{意图描述1}、{意图描述2}时，必须触发本技能。常见触发表达：{表达1}、{表达2}、{表达3}。注意：{否定约束}。
```

### 模板说明

| 占位符      | 填写规则                                             |
| ----------- | ---------------------------------------------------- |
| {关键词N}   | 从 SKILL.md 正文提取核心术语，包括中英文、大小写变体 |
| {意图描述N} | 用动宾短语描述用户意图，如"调用智能体"、"生成PPT"    |
| {表达N}     | 列举 3-5 个典型用户自然语言输入                      |
| {否定约束}  | 排除容易误触发的场景                                 |

## 诊断流程

| 步骤 | 执行动作             | 具体操作                   |
| ---- | -------------------- | -------------------------- |
| 1    | 读取目标 description | 运行 `Read` 读取 SKILL.md  |
| 2    | 五要素检查           | 逐项标记 ✅/❌，统计缺失项 |
| 3    | 输出诊断报告         | 按【诊断报告模板】输出     |

### 诊断报告模板

```
## Description 诊断报告：{skill-name}

**五要素符合度**：{通过数}/5 项 ✅

| 要素         | 状态 | 说明               |
|--------------|------|--------------------|
| 触发关键词   | ✅/❌ | {具体说明}         |
| 触发意图     | ✅/❌ | {具体说明}         |
| 常见用户表达 | ✅/❌ | {具体说明}         |
| 强制语气     | ✅/❌ | {具体说明}         |
| 否定约束     | ✅/❌ | {具体说明}         |

- {针对缺失项的具体优化建议}
```

## 正反对照

| ❌ 低级AI无法理解的写法              | ✅ 低级AI可以准确触发的写法                                                                           |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| "用于调用扣子平台的智能体来完成任务" | "当用户消息中出现'扣子'、'coze'等关键词，且意图涉及调用智能体时，必须触发本技能"                      |
| "帮助用户生成PPT演示文稿"            | "当用户说'生成PPT'、'做演示文稿'、'PPT美化'时，必须触发本技能。常见触发表达：做PPT、网页PPT、商业PPT" |

| "可以使用本技能"                     | "必须触发本技能"                                                                                      |
| 无否定约束                           | "注意：本技能仅支持X场景，不支持Y场景"                                                                |

## 输出格式

优化完成后，输出以下内容：

1. **修改前后对比**（Markdown 表格）
2. **改动理由**（逐条说明）
3. **五要素检查结果**（✅/❌）

---

## 错误处理

| 错误场景            | 错误表现                  | 处理方式                                        |
| ------------------- | ------------------------- | ----------------------------------------------- |
| 目标文件不存在      | `Read` 报错文件不存在     | 检查路径是否正确，询问用户确认 Skill 路径       |
| 目标文件非 SKILL.md | 文件不含 frontmatter 结构 | 输出"该文件不是有效的 Skill 文件"，说明结构要求 |
| description 已最优  | 五要素全部 ✅             | 输出"当前 description 已兼容低级AI，无需优化"   |
| 用户不认可优化结果  | 用户说"改回去"或"不对"    | 回滚更改，询问用户具体偏好，按偏好调整          |
