# 画曲线经验

> **何时读我**：作画规划阶段需要计算曲线采样点、选笔档、画细线（夹逼法）时。平时不读。

## 曲线采样

`gesture` 内部是相邻点直线连接，要看起来像曲线必须**密采样**：

| 点数 | 点间距 | 时长 | 效果 |
|---|---|---|---|
| 7 | ~150px | 1.5s | 折线感明显 |
| 21 | ~55px | 2.0s | 平滑 S 曲线 |

**经验值**：
- 点间距 **≤40px** 才看不到折角；
- 时长 **≥1500ms**；
- 整圆 ≈ 45 点（每 8° 一个）、半圆 ≈ 22 点、S 形 ≈ 21 点；
- 曲线坐标在 PC 端用数学公式算好再下发（圆心/半径用 §2 从 `qiu-board` 存储读到的实时值代入）：
  - 圆：`[cx + R*cosθ, cy + R*sinθ]`，θ 从 0° 到 360° 步 8°；
  - 正弦：`y = cy + A*sin((x-x0)/W*2π)`，每 40~50px 取一点。

## 轮廓嵌套填充法（Contour Nesting Fill）（2026-09-18 用户指导确立）

> **何时用**：画实心色块（圆/椭圆/任何闭合形状）需要填充时，**优先用此法，不要用水平直线堆叠**。

**问题**：用多条水平线堆叠填色，边缘是阶梯状锯齿，不圆滑；横线间距难控制，容易漏白或叠太厚。

**原理**：先沿目标形状的**外轮廓**画一圈闭合曲线，然后逐圈**向内偏移约一个笔宽的距离**再画一圈，靠画笔本身的宽度自然覆盖内部区域，直到圆心/中心。

**操作步骤**：
1. 确定目标形状的外轮廓半径（或任意闭合路径）；
2. 选好笔档，量得笔宽 `w`；
3. 从最外圈开始画闭合路径（圆/椭圆/任意形状）；
4. 半径向内缩 `w × 0.7~0.8`（留 20~30% 重叠保证无缝），画下一圈；
5. 重复直到半径 ≤ 半个笔宽（中心自然覆盖）。

**示例**：填 r=130 的实心圆，粗笔 w=81px：
- 第1圈 r=130（外轮廓）
- 第2圈 r=130-81×0.7 ≈ 74
- 第3圈 r=74-81×0.7 ≈ 17（中心，可省略直接停）
- 共 2~3 笔搞定，边缘全是光滑圆弧。

> **⚠️ 中心露底检查（2026-09-18 大漠皮肤实证）**：笔沿圆周走，实际只覆盖圆心周围 ±w/2 的范围。所以**最内圈半径必须 ≤ 0.4×w**，否则圆心周围会漏一个小圆点。上例第3圈 r=17 < 0.4×81=32.4，安全；但如果最内圈 r=47（>40.5），中心就会露黄点。即使下一圈半径算成负数，也要补画一个 r≈0.2×w 的小圈把中心盖住，**禁止跳过**。

**对比横线堆叠**：
| | 轮廓嵌套填充 | 横线堆叠 |
|---|---|---|
| 边缘 | 光滑圆弧 | 阶梯锯齿 |
| 笔数 | 2~3 笔 | 5~8 笔 |
| 均匀度 | 笔画自然重叠 | 间距难控，易漏白/过厚 |
| 适用形状 | 圆/椭圆/任意闭合轮廓 | 仅适合方形矩形 |

**铁律**：凡画实心圆/椭圆/弧形色块，**一律用轮廓嵌套填充法**，禁止用水平直线堆叠。

### 三角形/锥形的轮廓嵌套填充（2026-09-18 富士山作画实证）

> **何时用**：画锥形山、三角体、金字塔等三角形填充区域。

**与圆形的区别**：圆形每圈是同心圆，半径差小，2~3 圈就够；三角形中心到边的距离更大，**需要画 5~6 圈才能填满中心**，少了中心会露底（浅蓝小三角缺口）。

**操作步骤**：
1. 确定外轮廓三角形的三个顶点（左底、顶、右底）；
2. 每条边向内平移约 0.7×笔宽，得到下一圈相似三角形（中心不变）；
3. 重复 5~6 圈，直到最内圈小到中心无空隙；
4. 若有雪顶/分层效果，先画整座山的颜色，再在山顶画更小的三角形（白色）盖上去。

**示例**：富士山（粗笔 w=81）：
- 第1圈：底宽 680，高 490（外轮廓）
- 第2~6圈：每圈向内缩 57px（0.7×81），共 6 圈填满
- 雪顶：单独画 3 圈白色小三角形盖在山顶

**关键经验**：三角形向内偏移时，左右底向内收、底边向上移、顶边向下移，保持中心在同一竖轴上。

## 无压感画细线技法——夹逼法（2026-09-17 视频逐帧实证修正）

电子画板**无压感**，最细档笔画的线仍偏粗。要画比最细档还细的线（头发丝、衣褶线），用**夹逼法**——视频49秒真人作画逐帧确认：

**正确顺序（蓝底白线为例）：**
1. 先用**目标色中笔**画一条粗线
2. 切换成**背景色中笔**，沿粗线两侧各盖一笔，把边缘盖掉；
3. 中间露出的就是一条**比最细档笔还细**的线。

**白头发上的蓝线（头发丝）**：蓝色中笔画粗蓝块 → 白色中笔沿两侧盖掉 → 中间留细蓝条。

**核心**：不是"把线画细"，是"画粗了再用背景色笔修掉多余的"。中笔盖两遍可挤出远小于最细档的细线。

## 闭合圆铁律（2026-09-18 黑洞作画实证）

画整圆/闭合路径时，**points 数组最后一个点必须等于第一个点**（`pts.append(pts[0])`），手势路径才真正闭合。

- 反例：45 个等距点 θ=0°~352°，首尾差 8°——粗笔宽 81px 在小半径处还能盖住，但在 r=360 大半径处，8° 弧长 ≈ 50px，粗笔边缘盖不住，**右侧露出一条背景色缺口**；
- 正例：46 个点（45 等距点 + 回起点），gesture 绕一圈回到原点，首尾无缝；
- **所有画整圆的场景（轮廓嵌套填充、吸积环、圆盘扫掠）一律首尾重合**，半圆/弧线不闭合无需处理。

## 山丘/沙丘的画法（2026-09-18 大漠皮肤实证）

> **何时用**：画沙丘、山丘、远山等地面隆起物时。

**错误画法（水平香肠）**：x从左到右，y只上下波动15px —— 视觉上就是一条水平线，不像山丘。

**正确画法（∩形拱起）**：
- 山丘从地面向上拱起：左起点(x1,y1) → 山顶(中点, y1-拱高) → 右终点(x2,y1)
- 公式：`y = y1 - arch_h * sin(t*pi)`，t从0到1
- **拱起高度必须 ≥ 山丘宽度的1/5**，否则看起来还是水平线
- 近处山丘：拱起60~80px、宽300~400px；远处山丘：拱起20~30px、宽200~250px（近大远小透视）
- 多个山丘并排时大小不一、间距不一，不要等距排列
