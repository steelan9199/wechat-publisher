# 踩坑记录

> **何时读我**：遇到画错/断线/OCR 识别不到等异常，或沉淀/执行报错排查时。平时不读。
> 自进化规则：每次踩到新坑，追加一条（症状 → 原因 → 正确做法），保持简短。

## 已记录

1. **清空必须幂等（clearRounds 默认 2）**：清空操作若只点一次可能因弹窗时序没生效；用 `qiu-clear-board` 模板的 `clearRounds` 默认 2 重试，保证重复执行结果一致。沉淀脚本里必须沿用此写法。
2. **⛔ qiu-draw-batch 默认读手机上的 `qiu_batch.json`，不认你的新文件名（2026-09-18 真机踩到）**：上传了 `qiu_chick_batch1.json` 后不带 `file` 参数执行，结果跑的是手机上**旧版 `qiu_batch.json`**——`bg:0, border:0`、画的却是残留旧图案，背景边框完全没动，回执还 `ok:1` 假装成功。**正确做法二选一**：①上传时直接 `--target-name qiu_batch.json` 覆盖默认名；②执行时显式指定手机路径 `--args '{"file":"/storage/emulated/0/脚本/scripts-from-computer/files/<你的文件名>.json"}'`（路径用正斜杠）。**执行前先回执核对 counts 里的 `bg/border/path` 数是否符合预期，不对就立刻停**。

3. **⛔ 实心色块用了水平直线堆叠，被用户当场纠正（2026-09-18 富士山作画踩到）**：画富士山山体时下意识用多条横线从左到右堆叠填色，边缘阶梯锯齿、笔数多、不均匀。**正确做法：一律用轮廓嵌套填充法**——先画外轮廓闭合路径，再逐圈向内缩约 0.7×笔宽画下一圈，靠画笔宽度自然覆盖。详见 `画曲线经验.md`「轮廓嵌套填充法」。**自检：画实心色块前先想——我是在画闭合轮廓逐圈缩，还是在堆横线？**

4. **⛔ PowerShell 写 JSON 加了 BOM 头，手机端解析失败（2026-09-18 富士山作画踩到）**：用 `Out-File -Encoding utf8` 写 `qiu_batch.json`，传到手机执行时报 `Unexpected token: ﻿`（BOM 头）。**正确写法：用 .NET 写无 BOM UTF-8**：
   ```powershell
   [System.IO.File]::WriteAllText($path, $json, (New-Object System.Text.UTF8Encoding $false))
   ```
   **自检：凡是传给 qiu-draw-batch 的 JSON 文件，必须用上面这种无 BOM 写法，禁止用 Out-File -Encoding utf8**。

5. **⛔ 踩了坑不主动更新文档，要用户提醒才改（2026-09-18 自进化意识不足）**：画错方法、写坏 JSON 都是用户指出来才改文档。**正确做法：当场踩坑当场记录**——先改 SKILL.md 前置 SOP，再改踩坑记录，不等用户说。已升级为「第零位：自进化第一原则」。

6. **⛔ 行星用了与背景同色的颜料=隐形（2026-09-18 太阳系皮肤踩到）**：背景用 `blue` 铺底，地球也用 `blue` 画——球体与深蓝背景完全同色，自检图上地球只剩绿斑几乎看不见（OCR 描述为"灰色圆+绿点"）。**正确做法：主体色必须与背景色拉开对比；同色系主体要么换色（如地球改浅蓝），要么补高对比点缀（白色云朵点+绿色大陆斑块），画前在配色清单里逐项核对"主体 vs 背景"的色相对比**。自检：截图后先看主色元素是否从背景里"跳出来"。

7. **⛔ 多圆同排布局时粗笔视觉半径远大于几何半径，相邻圆粘成团（2026-09-18 后羿射日踩到）**：首版十个太阳沿单弧排列，间距按几何半径算（相邻 110~124px，太阳 R=36~60）——但粗笔 w=81 时每圆视觉半径 = R+40.5，间距需求 = R1+R2+81+余量，导致十阳连成"橙色云团"，自检图 OCR 描述为"一大团橙色云朵"。**正确做法：粗笔布局相邻圆心距必须 ≥ R1+R2+81+8（余量）；空间不够时改用上下两排交错排布（上排 4 大 + 下排 6 小交错插空），比单弧硬排多出近一倍空间**。自检：生成后渲染预览，用程序数连通块/看 OCR 描述是否"多个独立圆形"而非"一团"。
