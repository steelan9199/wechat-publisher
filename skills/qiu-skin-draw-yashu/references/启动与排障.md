# 启动与排障

> **何时读我**：服务健康检查失败、需要启动服务或配置防火墙时。正常运行时不读。

## 手机中继（autojs，端口 9421）

```powershell
# 健康检查
curl.exe -s http://localhost:9421/health
# 期望：{"status":"ok","phone":"connected",...}
# 若 phone:disconnected → 走手机连接排障；若连接拒绝 → 后台启动中继：
#   cd <autojs技能目录>; node scripts/autojs-relay-server.js （run_in_background:true）
```

## 电脑本地 OCR 服务（RapidOCR，8765）

**必须用它**——比手机内置 OCR 准，且返回带坐标可直接点击。

```powershell
# 健康检查
curl.exe -s http://127.0.0.1:8765/health
# 期望：{"code":0,"message":"ok",...}

# 未运行则启动（监听 0.0.0.0 允许手机访问）：
python "<local-ocr-asr-manager-yashu 技能目录>\scripts\service_manager.py" start ocr --host 0.0.0.0
```

**防火墙**（手机首次访问需放行一次）：

```powershell
netsh advfirewall firewall add rule name="Local OCR 8765" dir=in action=allow protocol=TCP localport=8765
```

**手机访问电脑 OCR 的地址**：手机端脚本自动读 `relay-config.json` 里的 `serverIp`，端口拼 8765。
