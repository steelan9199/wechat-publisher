# 文件名标点符号清理（clean-filename）

## 作用
把任意字符串里的标点符号规范化：**有对应中文标点的 ASCII 标点 → 替换成中文标点；没有对应中文标点的符号 → 直接删除**。返回可直接当作文件名使用的干净字符串（自动写回剪贴板）。

## 使用方法
技能目录附带 `clean_filename.js`。文件名作为「数据」通过 stdin / 剪贴板传入（**不要**作为命令行参数，否则单引号/双引号等会被 shell 转义干扰）。

1. **标准输入（推荐，heredoc 可含任意特殊字符）**：
   ```bash
   node clean_filename.js <<'EOF'
   你的'文件名"含*各种?特殊<字符>|的文件:名.md
   EOF
   ```
2. **剪贴板（最贴合工作流）**：复制脏名后直接运行 `node clean_filename.js`，脚本自动读取并写回剪贴板。
3. **管道（批量）**：`cat names.txt | node clean_filename.js`（names.txt 是待清洗文件名的文本文件，非脚本内置）。

运行后控制台打印「原始 / 清洗后」并提示已复制到剪贴板，Ctrl+V 粘贴即可。默认只返回结果字符串
