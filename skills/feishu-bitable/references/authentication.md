# 凭证管理指南

## 获取凭证

在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，获取 `App ID` 和 `App Secret`。

## 凭证管理规则

访问凭证 `tenant_access_token` 的最大有效期是 2 小时。整个凭证获取流程由 AI 自动处理，无需用户手动编辑配置文件。

### 凭证优先级

1. **第一优先级**：从 `config.default.json` 读取的有效凭证
2. **第二优先级**：用户当前对话中提供的凭证（AI 自动更新到配置文件）

### 自动处理流程

**步骤 1：检查现有配置**

- 读取 `config.default.json` 中的 `appId` 和 `appSecret`
- 判断是否为有效值（非空、非默认值、非占位符）

**步骤 2：根据情况自动处理**

| 场景                           | AI 行为                                      |
| ------------------------------ | -------------------------------------------- |
| 配置文件已有有效凭证           | 直接使用，无需额外操作                       |
| 配置文件无效，但用户提供了凭证 | **自动更新**配置文件，然后使用               |
| 配置文件无效，用户也未提供     | 询问用户获取凭证，获取后**自动更新**配置文件 |

**步骤 3：获取 tenant_access_token**

- 使用有效的 `appId` 和 `appSecret` 调用 API 获取 `tenant_access_token`
- 继续执行后续操作

### 用户感知

- AI 在自动更新配置文件后，**简要告知**用户："已自动将您的凭证保存到配置文件，方便下次使用"
- 整个流程对用户透明，无需用户手动编辑任何文件

## 获取凭证的脚本命令

```bash
node scripts/get-tenant-access-token.js --parameter-file-path params.json
```

参数文件示例 (`params.json`):

```json
{
  "appId": "cli_xxx",
  "appSecret": "xxx"
}
```

## 企业自建应用添加到飞书多维表格

1. 打开飞书多维表格
2. 点击右上角三个点
3. 点击更多/添加文档应用
4. 输入应用名称
5. 点击搜到的应用
6. 点击添加按钮

## 常见错误处理

| 错误场景   | 错误信息                       | 解决方案                                                               |
| ---------- | ------------------------------ | ---------------------------------------------------------------------- |
| 凭证无效   | `app_id or app_secret invalid` | 检查 App ID 和 App Secret 是否正确，确保是从飞书开放平台获取的有效凭证 |
| 应用未启用 | `app is not enabled`           | 在飞书开放平台启用应用，并确保应用状态为"已启用"                       |
| 权限不足   | `permission denied`            | 确认企业自建应用已添加到目标多维表格中                                 |
| Token 过期 | `tenant_access_token expired`  | 重新运行获取凭证脚本，Token 有效期约 2 小时                            |
| 网络错误   | `ECONNREFUSED` 或超时          | 检查网络连接，确认能访问飞书开放平台                                   |

详细错误码及解决方案参见 [常见错误及解决方案](errors.md)。
