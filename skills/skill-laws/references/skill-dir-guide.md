# $SKILL_DIR 详细指南

## 为什么要定义这个变量？

当 Skill 需要运行脚本或代码时，AI 必须知道"在哪个文件夹里执行"。如果路径不明确，AI 可能在 A 文件夹运行失败，在 B 文件夹也运行失败，找不到脚本文件。尤其是嵌套的 `scripts/` 目录，更容易搞错。因此，必须在文档中明确约定工作路径。

## $SKILL_DIR 是什么

`$SKILL_DIR` 指当前 Skill 所在的绝对目录，即 `SKILL.md` 文件所在的文件夹。它是一个变量名，供 AI 在执行时引用，避免硬编码具体路径。

## $SKILL_DIR 有什么用

1. **定位脚本**：Skill 的脚本通常放在 `$SKILL_DIR/scripts/` 目录下，AI 可以通过这个变量找到并运行它们。
2. **统一路径引用**：Skill 内部引用其他文件（如配置文件、参考文档）时，都可以基于 `$SKILL_DIR` 拼接路径，确保在任何机器上都能正确找到。
3. **明确脚本工作目录**：运行脚本时，AI 应该以 `$SKILL_DIR/scripts/` 为当前工作目录（cwd），脚本在这个目录下执行，而不是在 `$SKILL_DIR` 根目录执行。

## 怎么定义 $SKILL_DIR

在目标 Skill 的【环境说明】段落中，必须显式写出：

```markdown
- `$SKILL_DIR` = 当前 Skill 所在目录，即本文件 `SKILL.md` 所在的文件夹
- **调用脚本路径：** `$SKILL_DIR/scripts/`
```

## 什么时候需要定义

| Skill 类型    | 是否需要定义 `$SKILL_DIR` | 说明                            |
| ------------- | ------------------------- | ------------------------------- |
| 包含脚本/代码 | 必须定义                  | AI 需要知道脚本在哪里、从哪运行 |
| 纯文档/无代码 | 不需要                    | 没有脚本执行，路径约定不重要    |
