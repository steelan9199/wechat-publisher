# AI 复盘评分标准（scoring.md）

AI 在复盘阶段**亲自阅读**每个视频/直播间的 ASR 文本，按以下标准打分并写出理由。
**禁止用关键词匹配**——评分依据是你对内容的理解。

## 评分维度（总分 0-10）

| 维度 | 分值 | 判断依据（AI 理解式） |
|---|---|---|
| 信息量 | 0-4 | 内容是否有知识增量：讲清了一个概念/方法/事实/观点，还是空话套话 |
| 新奇度 | 0-3 | 是否让 AI 感到「这个我不知道/没想到」：冷知识、反常识、少见视角、新颖形式 |
| 表达质量 | 0-3 | 结构是否清晰、有具体案例/论证、制作是否用心、是否有记忆点 |
| 扣分 | −0~4 | 带货推销、纯喊口号、复读水内容、制造焦虑套路、标题党空壳 |

## 评分参考锚点

- **9-10 分**：信息量足 + 有反常识/新视角 + 表达清晰有记忆点（几乎没遇到过）
- **6-8 分**：有实质内容，让 AI 学到东西或引发思考
- **3-5 分**：普通内容，可看但不突出（大部分视频落在这里）
- **0-2 分**：纯带货、水内容、套路化、无信息量
- 直播间按同样标准评（它是"内容场"），并注明主播/话题主题

## 理由写法

用自然语言，**给出具体证据**（引用文本里的实际内容），让用户一眼看懂"AI 为什么感兴趣"。

好例子：
> 信息量+3：讲清了房贷利率计算逻辑，含具体数字（"提前还款反而亏"）；新奇度+2：反常识观点"还贷越早越亏"；表达质量+2：用两个具体例子演示。扣0。总分7。

坏例子（禁止）：
> 因为提到了"房贷"和"利率"，关键词命中。

## 主题标签（theme_tags）

用 1-3 个自然词概括内容类型，**不要预设分类**，从你读到的内容里归纳：
`知识科普`、`历史`、`美食教程`、`影视解说`、`情感故事`、`搞笑段子`、`财经`、`健身`、`旅游`、`职场`、`猎奇`、`带货`…

## 评分 JSON 格式（report.py score 的输入）

```json
[
  {"type": "video", "id": 1, "info": 3, "novel": 2, "quality": 2, "total": 7,
   "reason": "信息量+3：……；新奇度+2：……；表达质量+2：……。扣0。", "tags": "知识科普,财经"},
  {"type": "live", "id": 1, "info": 2, "novel": 1, "quality": 1, "total": 4,
   "reason": "……", "tags": "带货直播"}
]
```

## 工作流

1. `python scripts/report.py dump <session_id>` 分批读未评分文本（文本多时用 `--full` 看全文）
2. AI 逐条理解、打分、写理由、贴主题标签，生成 `scores.json`
3. `python scripts/report.py score <session_id> <scores.json>` 写回
4. `python scripts/report.py report <session_id>` 生成报告骨架，AI 补写「偏好画像」「自我总结」后交付
