# 组织架构图 · 专属视觉规则

> 本文件是组织架构图（organization chart / tree diagram）的专属视觉规则。绘制组织架构图时，除遵守 `design-system.md` 和 `svg-drawing-knowledge.md` 外，**必须**遵守本文件。
>
> 组织架构图表达「层级管辖关系」，顶层为根节点，逐层向下展开。它靠**直角折线**和**自上而下层级**建立结构——这与思维导图（曲线、放射）有本质区别，尽管两者都表达树形层级。

---

## 1. 视觉特征

组织架构图的核心视觉语法是三个字：**层、辖、列**。

- **层**——自上而下分层，每层代表一个组织层级（如：董事会 → 高管 → 部门 → 团队 → 个人）。层间用直角折线连接。
- **辖**——连线表达"管辖"关系（父节点管辖子节点），**不用箭头**——这与流程图（用箭头表达流向）不同。
- **列**——同级节点在同一水平线上等间距排列，垂直对齐到同一 y 坐标。

### 与思维导图的区别（最易混淆）

| 特征 | 组织架构图 | 思维导图 |
|------|------------|----------|
| 布局 | 纯自上而下 | 中心放射 |
| 连线 | 直角折线（水平+垂直段） | 贝塞尔曲线 |
| 方向 | 单向（向下展开） | 四向放射 |
| 根节点位置 | 顶部居中 | 画布正中 |
| 子节点排布 | 父节点正下方一排 | 父节点左右两侧 |
| 配色 | 按部门/分支着色 | 一分支一色族，子级变浅 |

## 2. 形状语义

| 节点类型 | 形状 | 含义 |
|----------|------|------|
| 标准节点 | 圆角矩形 | 职位 / 部门 / 角色 |
| 虚线节点 | 虚线圆角矩形 | 待招聘 / 空缺 / 虚线汇报 |
| 高亮节点 | 强调色填充 | 关键人物 / 当前焦点 |
| 多人共岗 | 矩形内叠两条横线 | 两人共同担任一职 |

组织架构图**只用圆角矩形**，不像流程图那样用菱形/椭圆——形状不携带语义，靠颜色和位置。

## 3. 坐标模板

### 3.1 标准 3-4 层布局

```
画布:       viewBox="0 0 680 H"
            H = 层数 × 120 + 60 (顶部标题)
标题:       x=340, y=34 (居中)

根节点:     cx=340, y=70 (顶部居中)
第2层:      y=190, 子节点等间距排开
第3层:      y=310, 每个第2层节点下再展开
第4层:      y=430 (如有)

节点框宽:   W=130 (组织架构图节点通常比架构图窄, 因为只写职位名)
节点高:     48 (单行) 或 56 (双行: 职位+姓名)
```

### 3.2 子节点排布公式

设某父节点 `cx = P`，它有 `n` 个子节点：

```
子节点间距:  gap = W + 20  (W=130 → gap=150)
子节点总宽:  total = (n-1) × gap
最左子节点:  cx_first = P - total / 2
第 i 个子节点: cx_i = P - total/2 + (i-1) × gap   (i=1..n)
```

例：父节点 cx=340，3 个子节点：
- total = 2 × 150 = 300
- cx = 340 - 150 = 190 / 340 / 340 + 150 = 490

### 3.3 连线画法（直角折线，核心特征）

从父节点底边中点到子节点顶边中点，走"下-平-下"三段直角折线：

```
父节点底边中点: (P, y_parent_bottom)
中转水平线 y:   y_mid = (y_parent_bottom + y_child_top) / 2
子节点顶边中点: (C, y_child_top)

折线 path:
  M P, y_parent_bottom
  L P, y_mid          (向下到中转线)
  L C, y_mid          (水平到子节点正上方)
  L C, y_child_top    (向下到子节点顶边)
```

**多子节点共享中转线**：同一父节点的所有子节点共用一条水平中转线，从最左子节点 cx 到最右子节点 cx。不要每个子节点单独画一条中转线——那样线条重叠混乱。

正确画法（共享中转线）：
```
M P, y_parent_bottom  L P, y_mid  L cx_leftmost, y_mid  L cx_leftmost, y_child_top
                                                       L cx_2, y_mid  L cx_2, y_child_top
                                                       ... (水平段在 y_mid 上连成一条)
```

简化为 `<path>`：
```
M P,y_parent_bottom V y_mid H cx_leftmost V y_child_top M cx_leftmost,y_mid H cx_rightmost
(再从每个子节点 cx 处 V y_child_top)
```

## 4. 节点尺寸

| 节点类型 | 高度 | 宽度 |
|----------|------|------|
| 单行节点（仅职位） | 44 | `字数 × 7 + 20`（组织图节点偏紧凑） |
| 双行节点（职位+姓名/人数） | 56 | `max(职位字数 × 7, 副行字数 × 6) + 20` |

**同级节点尺寸统一铁律**：同一层的所有节点必须等高、等宽（取该层最长文字算宽度，全层统一）。不同层可以不同尺寸（如高管层双行、基层单行）。

## 5. 箭头与连线

### 5.1 连线样式（核心特征）

- **直角折线**——纯水平段 + 纯垂直段，`<polyline>` 或 `<path>`。
- **无箭头**——组织架构图表达"管辖"而非"流向"，不画箭头。
- **禁止斜线**——任何斜线连接都是错的。
- **禁止曲线**——贝塞尔曲线是思维导图的专利，组织架构图不用。
- 线型：实线，灰 600 `#5F5E5A`，`stroke-width="1"`。
- 虚线汇报关系：`stroke-dasharray="4 3"`，表示非直接管辖（矩阵式管理的虚线汇报）。

### 5.2 连线规则

1. **父子必须垂直对齐**——子节点的水平中转线必须正好在父节点正下方出发。
2. **同父兄弟共享中转线**——同一父节点的子节点共用一条水平中转线。
3. **不同父的中转线不重叠**——如果两个父节点的中转线 y 相同且 x 范围重叠，会视觉混乱。解决：让不同父的中转线 y 错开 10-15px。
4. **连线不穿过节点**——折线必须绕过其他节点，不能横穿。

### 5.3 跨部门虚线汇报

矩阵式管理中，一个人可能有两个上司（实线 + 虚线）：

- 实线管辖：实线直角折线（默认）。
- 虚线汇报：虚线直角折线 `stroke-dasharray="4 3"`，可附小标签"虚线汇报"。

## 6. 配色策略

组织架构图按**部门/分支**着色，一部门一色系。

### 6.1 部门着色

| 部门示例 | 推荐色系 | 50 填充 | 600 描边 |
|----------|----------|---------|----------|
| 管理层 | gray | `#F1EFE8` | `#5F5E5A` |
| 技术部 | blue | `#E6F1FB` | `#185FA5` |
| 产品部 | purple | `#EEEDFE` | `#534AB7` |
| 市场部 | amber | `#FAEEDA` | `#BA7517` |
| 销售部 | green | `#EAF3DE` | `#3B6D11` |
| 人力部 | pink | `#FBEAF0` | `#993556` |
| 财务部 | teal | `#E1F5EE` | `#0F6E56` |

### 6.2 着色铁律

1. **同部门同色**——一个分支（部门）从根到叶用同一色系。
2. **跨部门换色**——不同一级部门用不同色系。
3. **根节点用中性色**——CEO/董事长用 gray 系，不偏任何部门。
4. **或仅高亮一支**——如果只想展示某条汇报线，全图灰系，高亮分支用强调色。
5. **色数 = 一级部门数**——通常 3-6 色。

### 6.3 层级明度（可选）

同一部门内，靠明度差表达层级（类似思维导图）：
- 第 2 层（部门总）：100 级填充
- 第 3 层（团队 lead）：50 级填充
- 第 4 层（个人）：50 级填充 + 无描边

但这不是强制——组织架构图也可以全部门同色，靠位置表达层级。

## 7. 常见反例

1. **连线非直角折线**——用斜线或曲线连接父子。必须直角折线。
2. **用箭头**——组织架构图无箭头（除非画虚线汇报）。
3. **父子节点不对齐**——子节点不在父节点正下方。中转线必须从父 cx 出发。
4. **同级节点尺寸不一**——同层节点高度/宽度不同。全层统一。
5. **中转线重叠**——多个父节点的水平中转线在同一 y 重叠。错开 10-15px。
6. **连线穿过节点**——折线横穿其他节点框。绕行。
7. **子节点溢出画布**——子节点太多超出安全区 [40, 640]。拆成多张图或缩小 W。
8. **根节点不居中**——根节点偏离画布水平中心。cx 必须 = 340。
9. **同父兄弟中转线不共享**——每个子节点单独画一条中转线，线条堆叠。共享一条水平段。
10. **部门配色混乱**——同部门用多色或跨部门同色。一部门一色系。
