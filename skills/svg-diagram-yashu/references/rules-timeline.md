# 时间线 · 专属视觉规则

> 本文件是时间线（timeline）的专属视觉规则。绘制时间线时，除遵守 `design-system.md` 和 `svg-drawing-knowledge.md` 外，**必须**遵守本文件。
>
> 时间线表达「沿时间轴排列的里程碑或事件序列」。它靠**水平时间轴**和**交替排布的事件卡片**建立结构——时间从左到右推进，事件卡片上下交替避免重叠。

---

## 1. 视觉特征

时间线的核心视觉语法是三个字：**轴、碑、卡**。

- **轴**——一条水平时间轴贯穿画布左右，是全图的视觉脊梁。轴上标刻度或年份。
- **碑**——里程碑用圆点标注在时间轴上，每个圆点对应一个时间节点。
- **卡**——事件描述用矩形卡片，上下交替排布在轴的上方和下方，用虚线连接到对应圆点。交替排布是为了避免卡片水平挤在一起。

### 与其他图的区别

| 特征 | 时间线 | 流程图 | 甘特图 |
|------|--------|--------|--------|
| 主轴 | 水平时间 | 流程方向 | 水平时间 + 垂直任务 |
| 节点 | 圆点里程碑 | 形状节点 | 任务条 |
| 连线 | 虚线（圆点到卡片） | 箭头 | 无（任务条本身） |
| 方向 | 严格左→右 | 上→下 或 左→右 | 左→右 |

---

## 2. 形状语义

| 元素 | 形状 | 含义 |
|------|------|------|
| 时间轴 | 水平实线 | 时间推进方向，左=早，右=晚 |
| 里程碑圆点 | 实心圆 | 一个时间节点/事件发生点 |
| 事件卡片 | 圆角矩形 | 事件的描述信息（标题+日期+说明） |
| 连接虚线 | 虚线 | 圆点与其事件卡片的对应关系 |
| 刻度标记 | 短竖线 | 时间轴上的时间刻度（如年份） |
| 阶段背景 | 浅色矩形（可选） | 划分时间段（如"Q1/Q2/Q3/Q4"） |

## 3. 坐标模板

### 3.1 标准水平时间线

```
画布:       viewBox="0 0 680 H"
            H = 顶部卡片区(160) + 轴区(40) + 底部卡片区(160) + 标题(40) = 400
            (事件多时 H 可到 460)
标题:       x=340, y=34 (居中)

时间轴:     y=240 (画布垂直中心偏下, 给上方卡片留 160px)
            x1=60 → x2=620 (安全区内, 留两端刻度空间)

里程碑圆点: 在时间轴上等间距分布
  N 个事件: cx_i = 60 + (i-1) × (560 / (N-1))   (i=1..N)
  圆点:     r=7, 实心, 该事件色系 600 级

事件卡片交替:
  奇数事件(1,3,5...): 卡片在轴上方, y_card = 100 (卡片顶), 高 100
  偶数事件(2,4,6...): 卡片在轴下方, y_card = 280 (卡片顶), 高 100

连接虚线:   从圆点到卡片底边/顶边中点
  上方卡片: x1=cx, y1=240(轴) → x2=cx, y2=200(卡片底)
  下方卡片: x1=cx, y1=240(轴) → x2=cx, y2=280(卡片顶)
```

### 3.2 事件卡片内部布局

```
卡片宽:     120px (统一)
卡片高:     100px
圆角:       rx="8"

卡片内文字:
  日期:     y = card_y + 22, 字号 12, 字重 500, 颜色 = 该事件色系 800
  标题:     y = card_y + 44, 字号 13, 字重 500, 颜色 #1f2937
  说明:     y = card_y + 66, 字号 11, 字重 400, 颜色 #5F5E5A
  (说明超长可换行到第二行, y = card_y + 82)
```

### 3.3 时间刻度

如果事件有明确日期，在时间轴下方标刻度：

```
刻度位置:   y=255 (轴下方 15px)
刻度文字:   字号 11, 颜色 #888780
刻度对齐:   text-anchor="middle", x = 圆点 cx
```

如果事件按时间均匀分布，刻度 = 事件日期；如果不均匀，需按实际时间比例排布圆点。

## 4. 节点尺寸

| 元素 | 尺寸 |
|------|------|
| 时间轴 | `stroke-width="2"`，灰 600 |
| 里程碑圆点 | 半径 7px，实心 |
| 强调里程碑 | 半径 10px + 强调色描边 |
| 事件卡片 | 120 × 100px，`rx="8"` |
| 连接虚线 | `stroke-dasharray="3 3"`，`stroke-width="1"`，灰 400 |
| 刻度标记 | 短竖线，长 6px |
| 卡片间距 | ≥140px（圆点间距，给卡片留空间） |

**卡片不重叠铁律**：相邻卡片（同侧）水平间距必须 > 卡片宽度 120px。如果事件密集到圆点间距 < 140px，要么减少事件数，要么增大画布宽度。

## 5. 箭头与连线

### 5.1 时间轴

- **水平实线**，灰 600 `#5F5E5A`，`stroke-width="2"`。
- **方向感**：右端可加箭头标记表示"时间流向未来"，或两端都不加（时间轴本身已隐含方向）。
- **笔直**：时间轴必须纯水平，不能弯折。

### 5.2 连接虚线

- 圆点到事件卡片用**虚线**连接，`stroke-dasharray="3 3"`，灰 400 `#888780`，`stroke-width="1"`。
- 虚线垂直（`x1=x2=cx`），从圆点到卡片近端中点。
- **无箭头**——虚线只表达"对应关系"，不表达流向。

### 5.3 事件间无连线

- 事件之间**不画连线**——时间轴本身已经表达了时序，不需要事件间再连线。
- 例外：如果想表达"事件 A 导致事件 B"的因果关系，可在两圆点间画弧形虚线箭头，但要谨慎，避免画面混乱。

## 6. 配色策略

时间线按**阶段/类别**着色，1-4 色。

### 6.1 阶段着色

| 用法 | 色数 | 说明 |
|------|------|------|
| 纯单色 | 1 | 全图蓝系或灰系，最简洁 |
| 按阶段着色 | 2-4 | 不同时间段（如"过去/现在/未来"或"Q1/Q2/Q3/Q4"）各一色 |
| 按类别着色 | 2-4 | 不同事件类型（如"产品发布/人事变动/融资"）各一色 |
| 高亮关键事件 | 1+1 | 全图单色，关键里程碑用 red 或 amber 强调 |

### 6.2 配色铁律

1. **同阶段事件同色**——圆点 + 卡片描边 + 日期文字共用该阶段色系。
2. **时间轴统一色**——不跟事件色，用中性灰 600。
3. **卡片背景统一浅灰**——`#F1EFE8`（gray 50），不跟事件色，让色系体现在圆点和描边上。
4. **强调事件用红/amber**——关键里程碑圆点加大 + 强调色。

### 6.3 阶段背景（可选）

如果想划分时间段（如季度），可在时间轴上方画浅色矩形背景：

```
阶段背景:   y=230, 高=20 (薄薄一条在轴上方)
  Q1: x=60-200, fill=blue 50
  Q2: x=200-340, fill=teal 50
  Q3: x=340-480, fill=amber 50
  Q4: x=480-620, fill=pink 50
阶段标签:  y=222, 居中于各阶段, 字号 11, 该色系 800
```

## 7. 常见反例

1. **时间轴不直**——弯折或倾斜。必须纯水平。
2. **事件卡片重叠**——同侧卡片水平间距不够。间距 ≥140px 或减少事件。
3. **圆点强行按时间比例排布**——timeline 的核心目的是展示"事件序列"而非"事件密度"。等距分布视觉节奏更平衡，不会因月份疏密导致圆点过紧或过松。如果需要表达事件密度，换用密度热力图或燃尽图，不要硬塞进 timeline。
4. **卡片全在同侧**——所有卡片都在轴上方，挤成一团。必须上下交替。
5. **连接线用实线**——实线让画面太"硬"。圆点到卡片用虚线。
6. **连接线有箭头**——虚线只表对应关系，无箭头。
7. **无日期/刻度**——读者不知道每个事件何时发生。必须标日期或刻度。
8. **卡片信息过载**——卡片里塞太多文字。精简到日期+标题+一行说明。
9. **时间轴无方向感**——不标"开始/结束"或箭头。右端加箭头或标方向。
10. **事件间乱连线**——每个事件都连线，画面变成蛛网。事件间不连线（除非有明确因果）。

## 8. 排版优化要点（迭代经验）

> 以下规则来自实际 SVG 迭代调试。即使坐标和形状都对，忽略这些细节仍会让图"看起来别扭"。

### 8.1 视觉对称三铁律

时间线的"舒服感"主要来自三重对称，缺一不可：

| 对称维度 | 规则 | 计算公式 |
|----------|------|----------|
| **上下对称** | 上方卡片到圆点的连接线长 = 下方卡片到圆点的连接线长 | `连接线长 = (卡片近端 - 圆点边缘)`，上下必须相等 |
| **左右对称** | 首圆点到画布左边缘 = 末圆点到画布右边缘 | `边距 = (680 - (N-1)×间距) / 2` |
| **圆点等距** | 相邻圆点间距完全相等 | `间距 = (末点x - 首点x) / (N-1)`，取整后微调到能整除 |

**示例（4 事件，画布 680）**：边距 45 + 间距 160 → 圆点 x = 100 / 260 / 420 / 580，左右各留 45px。

### 8.2 描边与字号下限

光栅化渲染（PNG）会"吃掉"过细的描边和过小的字号。下限值如下：

| 元素 | 下限 | 原因 |
|------|------|------|
| 卡片描边 | **1.5px**（终点卡 2px） | 0.5px 在 PNG 200dpi 下几乎消失 |
| 连接线 | **1.2px** | 1px 在抗锯齿后发虚 |
| 文字字号 | **11px** | 9-10px 糊成一团，信息层级塌陷 |
| 辅助文字颜色 | **#5F5E5A（灰 600）** | #888780（灰 400）在白底上对比度不足 |
| 主标题字号 | **20px / weight 700** | 14px / 500 作为标题过弱，与正文 13px 仅差 1px |

### 8.3 连接线：实线 vs 虚线

原规则（§5.2）要求圆点到卡片用虚线。**补充修正**：

- 连接线长度 ≤ 50px → **用实线**（颜色匹配阶段色 600），`stroke-width="1.2"`
- 连接线长度 > 50px → 可用虚线 `stroke-dasharray="3 3"`
- **原因**：虚线 `3 3` 在 40px 短线上只能呈现 6-7 段，视觉上像噪点而非"连接关系"

### 8.4 终点强调的完整方案

当时间轴末端是"终点事件"（如年度复盘、项目结项）时：

1. **去掉末端流向箭头**——箭头暗示"继续延伸"，与"终点"语义冲突
2. **圆点用双圈高亮**——外圈 r = 主圆点 r + 6（如 r=15 包裹 r=9），`fill="none" stroke="强调色 400" opacity="0.5"`
3. **连接线起点避开外圈**——从外圈下沿之外开始，不能穿过外圈
   - 错误：`y1=228`（在外圈 r=15 的 y=205-235 范围内）
   - 正确：`y1=236`（外圈下沿 y=235 之外 1px）
4. **终点卡片描边加粗**——`stroke-width="2"`（普通卡 1.5px）

### 8.5 阶段标签避让圆点

阶段背景带内的文字标签不能紧贴圆点：

- **水平间距 ≥ 8px**——文字端点距圆点边缘至少 8px，否则视觉粘连
- **背景带太短放不下时**——把标签移到背景带另一端（如"成长期"标签放在背景带右端而非左端，避开 7 月圆点）
- **标签颜色**——用该阶段色系 600（与圆点同色），强化语义关联

### 8.6 卡片信息层次模板

单张卡片建议包含 4 层信息，通过字号/字重/分隔线建立层次：

```
┌─────────────────────┐
│ ① 序号气泡          │  圆形 r=10，左上角，fill=阶段色，白字 11px/700
│                     │
│   主标题            │  14px / 600，居中，#1f2937
│   描述              │  11px / 400，居中，#5F5E5A
│   ─────────         │  分隔线 1px，#E5E2D8
│   数据条            │  11px / 400，居中，#888780（关键数字可加粗）
└─────────────────────┘
卡片尺寸: 110 × 100px, rx=10, stroke=阶段色 1.5px
```

**分隔线作用**：把"定性描述"和"定量数据"在视觉上分开，避免文字堆成一坨。

### 8.7 字体栈

时间线与全局一致，统一用 `design-system.md` 规定的字体栈：

```
font-family="-apple-system, BlinkMacSystemFont, 'PingFang SC', sans-serif"
```

该栈已含 Apple 系统预装的中文 PingFang SC（仅按名引用、不嵌入文件），中英文混排字形一致；`-apple-system` / `BlinkMacSystemFont` 在 macOS / Chrome 下调用系统 UI 字体，`sans-serif` 作最终兜底，跨机渲染稳定且无字体侵权风险。

### 8.8 时间标签：锚点一致 + 描边防重叠

> 时间标签（如"3 月""Q1""2024"）是圆点的语义注解，必须始终锚定到圆点本身，不能因卡片位置不同而"飘走"。本节规则来自一次实际迭代：4 个圆点中，上方节点的月份紧贴圆点，下方节点的月份却贴到了卡片顶部——视觉上月份"认错主人"。

#### 8.8.1 锚点一致性

月份/时间标签是**圆点的标签**，不是卡片的标签。不管卡片在轴上方还是下方，标签都必须紧贴圆点：

| 节点位置 | 标签位置 | 距圆点中心 |
|----------|----------|-----------|
| 卡片在轴上方 | 圆点**上方** | 18-22px |
| 卡片在轴下方 | 圆点**下方** | 18-22px |

**反例**：下方节点的月份放在圆点下方 42px（贴着卡片顶部）——月份看起来像卡片标题，与圆点的关联断裂。

**间距统一**：上下标签到圆点的距离必须相等（都 18-22px），否则上下视觉重量不平衡。

#### 8.8.2 文字描边防重叠

时间标签常落在连接线穿过的路径上（上方标签被连接线穿过，下方标签靠近连接线起点）。文字与线条重叠时，给文字加白描边让线条在文字处"断开"：

```svg
<text x="100" y="200"
      fill="#185FA5"
      stroke="#FFFFFF"
      stroke-width="4"
      paint-order="stroke fill"
      stroke-linejoin="round">3 月</text>
```

**关键属性**：
- `paint-order="stroke fill"`——先画描边再画填充，描边变成"白底"而非"边框"（默认顺序是先 fill 后 stroke，描边会盖住文字一半）
- `stroke-width="4"`——描边宽度约为字号的 1/3（12px 字号 → 4px 描边）
- `stroke-linejoin="round"`——圆角连接，避免笔画转角处出现尖刺

**反例**：不加描边时，连接线穿过"3 月"二字中间，虽然读者能猜出是几月，但视觉上有干扰，降低阅读流畅度。

**适用范围**：所有可能与连线/轴线重叠的文字标签（月份、刻度、阶段名）。卡片内部文字不与线条重叠，无需描边。

#### 8.8.3 下方连接线给标签让位

当月份标签紧贴圆点下方时，下方连接线不能从圆点下沿直接连到卡片（会穿过月份文字）。连接线起点要下移到月份文字下方：

```
圆点下沿:     y = cy + r = 228
月份标签中心:  y = 238 (圆点下方 18px)
月份标签下沿:  y ≈ 244
连接线起点:    y = 248 (标签下沿 + 4px 空隙)
连接线终点:    y = 270 (卡片顶部)
连接线长度:    22px (短于上方的 42px)
```

**权衡**：上下连接线长度会因此不对称（42 vs 22），但月份位置对称更重要——月份是时间锚点的标签，连接线只是对应关系的辅助线。可接受这个不对称，因为月份文字本身填补了视觉空间。

#### 8.8.4 阶段背景带端点避让圆点

阶段背景带（色块）的端点不要正好压在圆点上，否则圆点的颜色归属暧昧（圆点是阶段 B 的色，但被阶段 A 的色带包住一侧）：

- **错误**：起步期色带右端 x=260，正好压在 7 月圆点（cx=260）上
- **正确**：起步期色带右端 x=250，给 7 月圆点留 10px 缓冲

**缓冲量**：≥ 10px（圆点 r=8 + 2px 视觉间隙）。

#### 8.8.5 终点外圈半径与附近文字的平衡

终点双圈（§8.4）的外圈半径要兼顾"强调"和"不挤文字"。当月份标签紧贴圆点下方时，外圈过大侵占文字空间：

| 外圈 r | 外圈下沿到月份文字距离 | 评价 |
|--------|----------------------|------|
| 15 | 7px（太近） | 月份文字和外圈视觉粘连 |
| 12 | 12px（合适） | 强调足够，文字不挤 |
| 10 | 14px（偏松） | 强调感减弱 |

**经验值**：外圈 r = 主圆点 r + 3~4（如 r=9 主圆点 → r=12~13 外圈），既保持双圈层次，又不侵占下方文字空间。§8.4 原建议的"外圈 r = 主圆点 r + 6"在月份标签紧贴圆点时偏大，需按本节修正。

### 8.10 卡片文字不溢出方框（文字宽度估算）

卡片里的文字（标题 / 副标题 / 描述）必须完全落在方框内。文字一旦超过卡片可用宽度，就会爬出框边（如 "N" 落在框左外、"录" 落在框右外）——这是时间线最高频的翻车点。

文字宽度估算（基于 11px 字号，落笔前即可预判）：
- 中文字符 ≈ 11px（全角）
- 英文字符 ≈ 6px（比例字体）
- 空格 ≈ 4px
- 符号（· / - ( ) 等）≈ 6px
- 单行估算宽 = 中文字数 × 11 + 英文字数 × 6 + 空格数 × 4 + 符号数 × 6
- 卡片可用文字宽 = 卡片宽 − 2 × 内边距（内边距通常 12px，即可用宽 ≈ 卡片宽 − 24）

约束与处置：
- 估算宽 > 可用文字宽 → 必溢出。先加宽卡片（110 → 150px 是常见甜点宽度）；仍放不下则**拆两行**。
- 拆行原则：两行字符数尽量接近（每行估算宽 ≤ 可用宽 × 1.1），避免"一行极长、一行极短"。
- 混合中英文按系数累加，宁估宽不估窄（英文实际宽度常略大于 6px）。

反例（本次迭代）：原稿卡片宽 110px（可用宽 ≈ 86px），描述写 "NTFS 重解析点 · 仅限目录"（4 英文 + 8 中文 + 2 符号 ≈ 24 + 88 + 12 = 124px > 86px）→ 文字溢出框外。修正：卡片加宽到 150px，描述拆两行（"NTFS 重解析点" ≈ 72px / "仅限目录" ≈ 44px），每行均远小于可用宽 126px，稳稳在框内。

### 8.11 卡片内部上下留白均衡

卡片内文字块到上边框与下边框的间距应大致相等，且均 ≥ 12px（对齐 design-system 的"文字距边 ≥ 12px"）。禁止"顶部大片空白、底部文字贴边"或反之的失衡。

根因：角标类元素（编号圆球）若只贴在左上角，仅占角落一小块，导致右上大片空白；正文被顺序下推，末行常贴底边 → 上松下挤。

处置（三选一）：
- 去掉角标，正文整体居中、按 12px 上下内边距均匀排布（最省事，通用）
- 把序号做成横贯全宽的顶部色条（4px 高），填充顶部空间
- 把序号内嵌进标题行（"① 目录联接"），不另占一行

垂直分布模板（落笔前先算）：
- 卡片高 H、内容 N 行、行高 line_h、行间距 gap
- 总内容高 = Σ行高 + (N − 1) × gap
- 上下内边距 = (H − 总内容高) / 2，应各 ≥ 12px
- 若 < 12px → 加大 H 或减行数（时间线卡片常见 H = 100px 容纳 5 行：标题 14 + 副标题 11 + 分隔线 + 描述 × 2）

反例（本次迭代）：原稿卡高 110px，编号圆球贴左上（cy = 85，直径 20px），标题被推到 y = 110 → 卡顶到标题上沿约 33px 空白（右上尤其空），而底部第二行描述 y = 172 紧贴卡底 180（仅 2px）→ 上松下挤。修正：去掉编号圆球，卡高回到 100px，5 行内容按 12px 上下内边距均匀排布（标题 y = 89 顶距 12px、描述2 y = 153 底距 11.5px），呼吸感平衡。

### 8.12 自检清单

绘制完成后逐项检查：

- [ ] 圆点是否等距？首尾圆点到画布边缘是否对称？
- [ ] 上下连接线长度是否相等？
- [ ] 卡片描边 ≥ 1.5px？最小字号 ≥ 11px？
- [ ] 辅助文字颜色是否深于 #5F5E5A？
- [ ] 终点事件是否用了双圈高亮？连接线是否避开了外圈？
- [ ] 阶段标签是否紧贴圆点？（应 ≥ 8px 间距）
- [ ] 阶段背景带端点是否压住了圆点？（应留 ≥ 10px 缓冲）
- [ ] 时间标签（月份/季度）是否紧贴圆点？（上下都应 18-22px，不能贴到卡片上）
- [ ] 下方节点的连接线是否给月份标签让了位？（起点在月份文字下方，不穿过文字）
- [ ] 时间标签是否加了白描边？（`paint-order="stroke fill"`，描边宽 ≈ 字号 1/3）
- [ ] 终点外圈半径是否过大挤压了月份文字？（r ≤ 主圆点 r + 4）
- [ ] 时间轴末端是否有不必要的流向箭头？（终点事件应去掉）
- [ ] 是否使用了全局字体栈（含 PingFang SC）？
- [ ] 卡片内每行文字估算宽是否 ≤ 可用宽？（中文 ≈ 11px / 英文 ≈ 6px / 空格 ≈ 4px / 符号 ≈ 6px；超出则加宽卡片或拆两行，见 §8.10）
- [ ] 卡片上下内边距是否均 ≥ 12px？（顶部无大片空白、底部文字不贴边；角标勿只占一角，见 §8.11）
