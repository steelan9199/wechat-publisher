# 循环图 · 专属视觉规则

> 本文件是循环图（cycle diagram）的专属视觉规则。绘制循环图时，除遵守 `design-system.md` 和 `svg-drawing-knowledge.md` 外，**必须**遵守本文件。
>
> 循环图表达「多个阶段首尾相连形成的闭环过程」。它靠**环形排列的节点**和**曲线箭头**建立结构——每个阶段是一环，阶段间用曲线箭头连接形成闭环。经典应用包括 PDCA 循环、敏捷迭代、产品生命周期、四季循环。

---

## 1. 视觉特征

循环图的核心视觉语法是三个字：**环、阶、向**。

- **环**——4-5 个节点围绕中心呈环形排列，视觉上形成一个圆环。环形是循环图的核心识别特征。
- **阶**——每个节点代表一个阶段，节点用圆角矩形，内写阶段名。每阶段用不同色系区分。
- **向**——节点间用曲线箭头连接，箭头方向统一（全顺时针或全逆时针），形成闭环。方向不一致 = 循环断裂。

### 与其他图的区别

| 特征 | 循环图 | 流程图 | 中心辐射图 |
|------|--------|--------|------------|
| 布局 | 环形 | 线性 | 中心向外 |
| 箭头 | 曲线箭头成环 | 直线箭头 | 通常无箭头 |
| 闭环 | 必须 | 可选（回环） | 无 |
| 节点数 | 4-5（固定少） | 任意 | 任意 |
| 语义 | 周而复始 | 一次性流程 | 中心辐射 |

---

## 2. 形状语义

| 元素 | 形状 | 含义 |
|------|------|------|
| 阶段节点 | 圆角矩形 | 一个阶段/环节 |
| 连接箭头 | 曲线 + 箭头 | 阶段间的推进方向 |
| 中心标签 | 文字（可选） | 循环的整体名称（如"PDCA"、"迭代环"） |

循环图**只用圆角矩形**表示节点，不靠形状区分——靠**色系**区分阶段。

## 3. 坐标模板

### 3.1 标准环形布局（4 节点）

```
画布:       viewBox="0 0 680 480"
标题:       x=340, y=34 (居中)

环心:       cx=340, cy=260
环半径:     R=160 (节点中心到环心的距离)

4 节点位置 (从顶部开始, 顺时针):
  节点1 (顶):    (340, 100)   — 12 点钟
  节点2 (右):    (500, 260)   — 3 点钟
  节点3 (底):    (340, 420)   — 6 点钟
  节点4 (左):    (180, 260)   — 9 点钟

节点框:      宽 130, 高 56, rx=8
  节点中心对齐到上述坐标 (rect x = cx-65, y = cy-28)
```

### 3.2 5 节点环形布局

```
环心:       cx=340, cy=260
环半径:     R=170

5 节点位置 (从顶部开始, 顺时针, 每个间隔 72°):
  节点1 (顶):       (340, 90)      — 0° (12点)
  节点2 (右上):     (502, 207)     — 72°
  节点3 (右下):     (440, 387)     — 144°
  节点4 (左下):     (240, 387)     — 216°
  节点5 (左上):     (178, 207)     — 288°

角度公式 (i=1..N, N=节点数):
  θ_i = -90° + (i-1) × (360° / N)   (从12点开始顺时针)
  x_i = 340 + R × cos(θ_i)
  y_i = 260 + R × sin(θ_i)
```

### 3.3 曲线箭头画法

节点间用**沿环圆弧的曲线**连接，不用直线：

```
从节点 i 到节点 i+1 (沿环顺时针):
  使用 SVG <path> 的 A (圆弧) 命令:
  M x_i_edge, y_i_edge  A R,R 0 0 1 x_{i+1}_edge, y_{i+1}_edge

  x_i_edge = 节点 i 朝向节点 i+1 的边缘点
  R = 端点到环心的距离（弧心 = 环心）
  large-arc-flag=0 (短弧), sweep-flag=1 (顺时针)
```

> 节点边缘点 = 从节点中心沿环切线方向偏移到节点矩形边缘。简化处理：从节点中心向下一节点中心方向延伸到矩形边缘。

#### 弧心必须 = 环心（关键）

**铁律：所有 8 个箭头端点必须等距于环心（即位于同一圆上），弧线半径 R = 该距离。** 这保证四段弧线弧心都重合于环心，拼接出**单一正圆**。

对于标准 4 节点模板（W=130, H=56, R_node=160）：

- 上下节点（选题/发布）的内边缘（y=128 / y=392）到环心距离 = 160 - 28 = 132
- 左右节点（创作/复盘）的内边缘（x=435 / x=245）到环心距离 = 160 - 65 = 95

因为不同边到环心距离不等，**不能简单用节点中心环半径 R_node=160 当 R**，必须按端点实际所在的圆计算 R。

**推荐取值 R=135**（在上下框内边缘外侧 3px，左右框外侧 40px）：

- 上下框底/顶边上各有 2 个端点（x=312 和 x=368，间距 56）
- 左右框顶/底边上各有 1 个端点（x=208 和 x=472）
- 所有 8 端点位于半径 135 的圆上，弧心 = (340, 260)，环是正圆

> **反例**：直接用 R_node=160 当 R（端点实际在半径 132-140 的圆上）。结果：弧心偏离环心，四段弧拼接出"鸡蛋形"非正圆，肉眼可辨。

### 3.4 闭环确认

最后一个节点（i=N）必须用曲线箭头连回第一个节点（i=1），形成闭环。**漏画这条闭环箭头 = 循环图失败**。

## 4. 节点尺寸

| 元素 | 尺寸 |
|------|------|
| 阶段节点 | 130 × 56px（双行：阶段名+说明），`rx="8"` |
| 单行节点 | 130 × 44px（仅阶段名） |
| 节点间距 | 弧长 ≥80px（给箭头标签留空间） |

### 4.1 文字层级（必须拉开）

循环图有四层文字，**字号字重必须明显区分**，不能撞车：

| 层级 | 元素 | 字号 / 字重 | 颜色 |
|------|------|-------------|------|
| L1 焦点 | 中心循环名（如 PDCA、迭代环） | 18-20px / 700 | gray 800 `#444441` |
| L2 标题 | 页面主标题 | 16px / 600 | gray 800 `#1f2937` |
| L3 节点主 | 阶段名（选题/创作等） | 14px / 500 | gray 800 `#1f2937` |
| L4 节点副 | 阶段说明（找方向/出内容） | 12px / 400 | gray 500 `#5F5E5A` |
| L4 中心副 | 中心副标题（持续优化） | 12-13px / 400 | gray 500 `#5F5E5A` |

**铁律**：

1. **中心循环名必须是视觉焦点**——字号 ≥18px、字重 ≥700，比所有其他文字都大且重。它是循环图的"主语"，权重不够 = 焦点缺失。
2. **页面标题 > 节点主文字**——标题字号或字重必须大于节点主文字，否则层级撞车、扫一眼分不清谁是标题谁是节点。
3. **相邻层级字号差 ≥2px 或字重差 ≥100**——不能出现"标题和节点主文字都是 14/500"这种平级。

**节点统一尺寸铁律**：所有阶段节点必须等大。循环图强调"各阶段平等轮转"，节点大小不一会暗示某阶段更重要——除非有意高亮某阶段，否则全统 一。

## 5. 箭头与连线

### 5.1 曲线箭头（核心特征）

- **圆弧曲线**——用 SVG `<path>` 的 `A`（arc）命令画圆弧，弧线沿环圆走，不用直线。
- **有箭头**——每段弧线末端加 `marker-end="url(#arrow)"`。
- **方向统一**——全图所有箭头顺时针，或全逆时针。**绝不能混用**。
- 线型：实线，`stroke-width="1.5"`，灰 600 `#5F5E5A`。

### 5.2 箭头标签（可选）

- 每段弧线上可标阶段转换的动作（如 PDCA 中"执行→检查"标"测量"）。
- 标签放在弧线外侧，距弧线 10px。
- 字号 11px，颜色 `#888780`。
- 标签不要压在弧线上。

### 5.3 禁止样式

- **禁止直线连接**——直线让"环"感消失，变成多边形。
- **禁止直角折线**——那是流程图或组织架构图。
- **禁止双向箭头**——循环图箭头单向，表达"推进到下一阶段"。
- **禁止漏画闭环箭头**——最后节点必须回到第一节点。

### 5.4 箭头入/出点对称

- 每个节点上的**入箭头端点和出箭头端点必须关于该节点的中心轴对称**。
- 标准偏移：从节点边缘中点向两侧各偏移 28px（130 宽边上入出点相距 56px，距两角各 37px）。
- 反例：入点在角附近、出点在中点——视觉上动线歪斜，节点像被"擦边"。
- 反例：入出点都堆在中点附近——箭头挤成一团，节点边缘动线不清。

## 6. 配色策略

循环图按**阶段**着色，每阶段一色系，色数 = 阶段数。

### 6.1 阶段配色（4-5 节点）

| 阶段序号 | 推荐色系 | 50 填充 | 600 描边 | 800 文字 |
|----------|----------|---------|----------|----------|
| 阶段1 | blue | `#E6F1FB` | `#185FA5` | `#0C447C` |
| 阶段2 | teal | `#E1F5EE` | `#0F6E56` | `#085041` |
| 阶段3 | amber | `#FAEEDA` | `#BA7517` | `#633806` |
| 阶段4 | purple | `#EEEDFE` | `#534AB7` | `#3C3489` |
| 阶段5（如需） | coral | `#FAECE7` | `#993C1D` | `#712B13` |

### 6.2 配色铁律

1. **色数 = 阶段数**——4 阶段 4 色，5 阶段 5 色。
2. **每阶段独立色系**——不用明度差表达层级（循环图各阶段平等，无层级）。
3. **箭头统一灰色**——曲线箭头用灰 600，不跟阶段色。
4. **中心标签用中性色**——gray 800 `#444441`，不偏任何阶段。
5. **阶段顺序色相递进**——按色环顺序选色（蓝→青→琥珀→紫），视觉上有"流转"感。

### 6.3 中心区域

- 中心放循环名称（如"PDCA 质量环"、"迭代环"），字号按 §4.1 L1 焦点级（18-20px / 700）。
- 中心区域留白，不堆元素。

#### 禁止在环内画装饰图形

**铁律：环形内部禁止画虚线、实线圆、椭圆、或任何装饰性闭合曲线。** 中心只放文字标签，靠纯留白当舞台。

理由：

1. **环形结构已由 4 段弧线箭头自身表达**——箭头就是环，再画一个虚线圆/椭圆去"暗示"环，是信息冗余。
2. **几何冲突**——节点通常是非正方形（如 130×56），任何居中圆/椭圆都很难同时贴四框内侧，必然制造"贴一边够不到另一边"的不等距问题。
3. **侵占中心留白**——循环图中心应是干净的"呼吸空间"，给中心文字一个舞台，虚线圆把舞台圈住反而拥挤。
4. **视觉噪声**——细虚线既不够强成为视觉元素，又不够弱完全隐入背景，卡在中间抢戏。

> 例外：仅当箭头不足以表达环形结构时（如 3 节点且箭头很短、环不闭合），才可考虑补一个虚线圆。4 节点 + 完整闭环箭头的情况，**一律不画**。

## 7. 流程顺序与命名

### 7.1 顺序与命名必须一致

**铁律：若中心标签引用了具名方法论（PDCA / DMAIC / OODA 等），节点的顺时针顺序必须严格匹配该方法论的标准顺序。**

| 方法论 | 标准顺序（顺时针） |
|--------|---------------------|
| PDCA | Plan → Do → Check → Act |
| DMAIC | Define → Measure → Analyze → Improve → Control |
| OODA | Observe → Orient → Decide → Act |
| 5S | 整理 → 整顿 → 清扫 → 清洁 → 素养 |

**如果实际业务流程顺序与具名方法论的顺序冲突**，二选一：

1. **改顺序**——调整节点位置/标签使其匹配方法论标准顺序。
2. **改命名**——中心标签换成中性词（如"迭代环"、"内容飞轮"、"质量环"），同时去掉节点副文字里的方法论字母（Plan/Do 等）。

> **反例**：中心写"PDCA"，但顺时针走 Plan → Do → Act → Check（Check 和 Act 互换）。懂 PDCA 的人会立刻看出顺序错乱，可信度受损。

### 7.2 业务流程的合理性

即便不引用具名方法论，业务流程本身也要符合常识顺序（如内容创作：选题 → 创作 → 发布 → 复盘，不能跳过"发布"直接"复盘"）。

## 8. 常见反例

1. **节点不在圆周上**——节点位置随意，不在同一圆周上。必须用角度公式精确计算。
2. **箭头方向不一致**——有的顺时针、有的逆时针。全图统一一个方向。
3. **漏画闭环箭头**——最后节点没连回第一节点。循环图必须闭环。
4. **用直线连接**——直线让环感消失。必须用圆弧曲线。
5. **节点大小不一**——暗示某阶段更重要。除非有意高亮，否则统一尺寸。
6. **阶段数过多**——超过 6 个节点环太挤。控制在 4-5 个，最多 6。
7. **箭头标签压在弧线上**——标签和弧线重叠。标签放弧线外侧 10px。
8. **中心堆满元素**——中心放太多文字或图标。中心留白或只放循环名。
9. **双向箭头**——循环图箭头单向推进。
10. **色系不区分阶段**——所有节点同色，失去阶段识别。每阶段独立色。
11. **中心装饰不等距**——虚线圆到四节点内侧距离不一（如左右 gap 15、上下 gap 52），中心感缺失。节点非正方形时必须用椭圆，按 §6.3 公式计算。
12. **文字层级撞车**——页面标题、中心循环名、节点主文字字号字重相同（如都是 14/500），扫一眼分不清主次。按 §4.1 拉开四级层级。
13. **中心循环名权重过低**——中心标签字号 ≤ 节点主文字，焦点缺失。中心名必须 ≥18px/700。
14. **流程顺序与命名不符**——中心写"PDCA"但顺序是 PDAC。按 §7.1 严格匹配或换中性命名。
15. **箭头入出点不对称**——节点上入箭头和出箭头关于中心轴不对称，动线歪斜。按 §5.4 标准偏移 28px。
16. **弧心偏离环心**——弧线半径与端点到环心距离不等（如 R=160 但端点实际在半径 135 上），导致四段弧弧心不重合，环形成"鸡蛋形"非正圆。所有 8 个端点必须等距于环心，R = 该距离。按 §3.3 公式计算。
17. **环内画虚线圆/椭圆**——在环形内部画装饰性虚线圆、实线圆或椭圆。环形结构已由箭头自身表达，属冗余装饰，且制造不等距几何冲突、侵占中心留白。4 节点闭环情况一律禁止。按 §6.3。
