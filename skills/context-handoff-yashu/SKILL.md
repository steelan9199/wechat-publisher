# 上下文交接

将当前对话的完整上下文总结为一份结构化的交接文档，保存到当前工作区根目录下的 `handoff-YYYYMMDD-HHMMSS.md` 文件中。让新的 AI agent 阅读该文档后即可无缝继续对话。

## 交接文档应包含以下内容

1. **对话背景与目标**：当前正在讨论或解决什么事情、最终想要达成什么结果。
2. **已完成的进展**：到目前为止已经做了哪些工作、达成了哪些共识或成果、解决了哪些子问题。
3. **当前状态与待办事项**：
   - 正在进行但尚未完成的事项；
   - 下一步明确需要执行的任务；
   - 存在的阻塞点、待确认的问题或待做的决策。
4. **关键决策与方案**：当前已确定的方向、原则、方法或结论。如果对话中涉及选择或取舍，需记录最终定下的方案。
5. **产出物与变更摘要**：如果对话中产生了任何内容（如文本、代码、配置、计划、列表、分析等），列出关键产出物的摘要或存放位置。不要贴完整内容，只写要点和路径。
6. **建议调用的 Skills**：根据当前任务类型，建议新 agent 继续工作时可以调用的相关 skills。
7. **脱敏提醒**：文档中必须隐去所有敏感信息，包括 API Key、密码、Token、个人隐私信息等。

## 引用规范

- 不要重复已存在于其他文档、计划、记录中的详细内容。
- 对于这些内容，在交接文档中通过文件路径或 URL 引用即可。

## 参数处理

如果用户传递了参数，将其视为对“下一会话重点方向”的描述，并在交接文档中突出体现，帮助新 agent 明确接下来的工作重心。

## 输出格式

- 交接文档使用 Markdown 格式。
- 文件名必须为 `handoff-YYYYMMDD-HHMMSS.md`，其中时间戳必须基于**用户设备的本地真实时间**。
- **严禁编造时间戳**。获取当前时间的跨平台方式如下：
  - **Windows (PowerShell)**: `Get-Date -Format "yyyyMMdd-HHmmss"`
  - **Linux / macOS / Bash**: `date +%Y%m%d-%H%M%S`
  - **Python**: `import datetime; datetime.datetime.now().strftime("%Y%m%d-%H%M%S")`
  - **Node.js**: `new Date().toLocaleString('sv').replace(/[- :]/g, '').slice(0, 12)`
- 如果执行环境支持调用系统命令，必须优先通过系统命令获取真实时间后再生成文件。
- 将文件保存到当前工作区根目录，确保新 agent 能快速定位并理解上下文。
