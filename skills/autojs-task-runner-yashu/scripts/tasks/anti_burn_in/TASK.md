# 防止烧屏 · 全屏悬浮遮罩防 OLED 烧屏

## 使用场景

- 手机长时间显示固定画面（如挂机游戏、导航、看视频）后，用黑色/纯色/渐变遮罩盖住屏幕，避免 OLED 像素长期点亮导致烧屏。
- 三阶段循环：纯黑（约 1 秒）→ 纯蓝（约 1 秒）→ 随机渐变（约 1 秒），共约 9 秒后自动关闭悬浮窗。
- 遮罩 `setTouchable(false)`，不阻挡下层界面的点击/操作；并通过反射设置窗口标志位，让遮罩覆盖状态栏、延伸到屏幕最顶端。
- **触发方式**：用户说"防止烧屏"即运行本模板（`node run_task.js anti_burn_in`）。

## 什么时候不该用

- 需要遮罩**常驻不关闭**的场景（如一直盖着屏幕当滤镜）：本模板运行约 9 秒后会自动 `w.close()` 关闭，不适合常驻。
- 需要支付等红线操作时：但凡涉及支付、转账、删除等不可逆操作，不在此模板范围内，须走安全确认流程（本模板本身不含此类操作）。

## 参数细节与坑

- 本模板**无参数**，AI 下发时直接 `node run_task.js anti_burn_in`，不要传 `--args`。
- 透明度等颜色参数写死在脚本内的 `COLOR_ALPHA` / `BLACK_ALPHA` 常量（用户明确要求不要改动颜色逻辑），需要调节时由人工改脚本，不要经 args 传入。
- 依赖 AutoJS6 的 `floaty.rawWindow` 与反射拿 `RawWindow` 设置窗口标志位，**必须授予手机端『悬浮窗权限』**，否则窗口创建失败。
- 遮罩可穿透点击，故它是"显示层"而非"操作层"，不会替代任何 UI 交互。

## 错误处理与兜底

- 若悬浮窗权限未授予 / `floaty` 创建失败，脚本抛错，回执 `{ok:0, err:"..."}`，AI 应提示用户去 AutoJs6 开启悬浮窗权限后重试。
- 成功回执 `{ok:1}`（极简，符合省 token 约定）。
