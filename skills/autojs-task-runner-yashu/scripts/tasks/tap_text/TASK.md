# tap_text · 点按含指定文字的控件

## 使用场景
- 有明确可见文字的按钮/列表项/标签（"确定""设置""保存"等）。
- 多步任务里替代脆弱坐标：先用 `inspect_control_by_coord` 拿到 text，再用本模板点。

## 什么时候不该用
- 文字会变（动态内容）或含特殊符号易错配时，优先用 `inspect_control_by_coord` 拿 id 再定位。
- 纯图标无文字的控件，本模板无效，改用坐标或 id。

## 参数细节与坑
- `text` 必须非空字符串。先 `text(t)` 精确匹配（3s 超时），再 `textContains(t)` 模糊包含（1.5s）。
- 沿父链最多上溯 5 层找 `clickable()` 祖先；整条链都不可点才 `click(中心坐标)`。
- 找多个同名文本时取第一个，可能点错项——列表场景最好先滚动/缩小范围。

## 错误处理与兜底
- 找不到：`{ok:0, err:"屏幕上未找到文本: xxx"}` → AI 应截图看屏、确认文字或换策略。
- 点中心坐标兜底可能点偏，建议后续步骤校验。

## 示例调用
```bash
node run_task.js --path tasks/tap_text/tap_text.js --args '{"text":"确定"}'
```
