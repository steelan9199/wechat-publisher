# 报告模板

本文件定义 skill-tester 各阶段报告的格式。报告必须遵循"结果优先、详情折叠"原则，让用户一眼看到当前阶段的核心结论。

## 报告文件命名

| 阶段           | 文件名                                  |
| -------------- | --------------------------------------- |
| 阶段1 正常场景 | `{skill-name}-test-report-normal.md`    |

## 报告模板

```markdown
# Skill 测试报告：{skill-name} - {stage-name}

**测试时间**：{timestamp}
**测试器版本**：skill-tester v{version}
**目标 Skill**：{skill-path}
**本阶段**：{stage-name}

---
```

## 凭证预检区块模板

### 预检全部有效

```markdown
| #   | 凭证名称 | 预检方式 | 预检结果 | 判定 |
| --- | -------- | -------- | -------- | ---- |

{precheck_rows}

所有必需凭证预检通过，进入真实测试。
```

### 预检部分失效

```markdown
| #   | 凭证名称 | 预检方式 | 预检结果 | 判定 |
| --- | -------- | -------- | -------- | ---- |

{precheck_rows}

**失效凭证**：{invalid_credentials}
**影响**：依赖失效凭证的场景标记"跳过（凭证失效）"，其余场景正常测试。
```

### 预检全部失效（测试终止）

```markdown
| #   | 凭证名称 | 预检方式 | 预检结果 | 判定 |
| --- | -------- | -------- | -------- | ---- |

{precheck_rows}

**所有必需凭证均失效，测试在预检阶段终止。**

终止原因：{termination_reason}
```

## 场景详情区块模板

每个场景渲染为独立小节，按功能分组：

````markdown
#### {功能名} - {scenario-id}

**模拟用户输入**：{simulated_input}

**综合结果**：{通过 / 部分通过 / 失败 / 跳过（缺凭证） / 跳过（凭证失效）}

**产出物对比**：

| 预期输出                                           | 实际输出        | 匹配判定               |
| -------------------------------------------------- | --------------- | ---------------------- |
| {expected_output}（来源：{SKILL.md声明 / AI推断}） | {actual_output} | {一致/部分一致/不一致} |

> 匹配判定说明：{match_explanation}
>
> 产出物记录方式：文本类直接记录文本；链接类（如图片URL）记录链接；文件类记录本地绝对路径。仅阶段1（正常场景）适用。

**关键契约**：

| 契约ID | 描述 | 判定 |
| ------ | ---- | ---- |
| C1     | ...  | 满足 |

**通用维度**：

| 维度       | 判定   |
| ---------- | ------ |
| 指令遵循度 | 通过   |
| 步骤完整度 | 通过   |
| 资源有效性 | 通过   |
| 输出合规性 | 通过   |
| 异常处理   | 不适用 |
| 触发准确性 | 通过   |

**执行证据**：

- 实际执行步骤：{actual_steps}
- 调用的工具/脚本：{tools_called}
- 最终输出：
  ```
  {final_output}
  ```
- 遇到的异常：{exceptions}
````

> **跳过场景**：仍展示场景 ID、综合结果和跳过原因，不渲染执行证据区块。

## 格式要求

- 报告使用纯文本标记状态（通过/部分通过/失败/跳过），不使用 emoji
- 敏感凭证（token、secret 等）脱敏显示，仅保留前后各 4 个字符，中间用 `****` 替代
- 通过率计算：`pass / (pass + partial + fail) * 100`，跳过的场景不计入分母，保留一位小数
- 最终输出过长时保留前后各 500 字符，中间用 `...（省略 N 字符）...` 标注
- 工具调用返回结果过长时同样截断并标注
