## 1.4 冲突裁决

- 语义与推荐做法 → 在线文档。
- 字段名与签名 → 已装 SDK 的类型定义。
- 两者冲突 → 按 SDK 写，并标注差异。
- 文档不可达 → 用已装 SDK 类型，声明「未能核对在线文档」，不编造版本相关细节。
- 技能、本提示词、§7.3 旧结论**都可能过时** → 一律以当次 `llms.txt` 为准，**不静默择一**。
