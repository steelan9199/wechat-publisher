# L2 金观涛层：可能性空间、共轭控制、黑箱、突变

来源：金观涛、（美）华国凡《控制论与科学方法论》，成稿于 1970 年代，1983 年科学普及出版社初版，2025 年广东人民出版社修订再版。

## 核心主张

> 事物的发展存在多种可能性，控制就是**在可能性空间中做有方向的选择**，并使事物朝着选定的目标转化。

维纳回答"系统是什么"，钱学森回答"怎么设计"，金观涛回答的是最前面那一步：**怎么定义问题、怎么选择策略、怎么认识一个看不透的对象。**

## 1. 可能性空间

控制的起点不是目标，而是**承认对象有多种走向**。

控制的三步：
1. 了解事物面临的可能性空间是什么
2. 在可能性空间中选择某一个状态作为目标
3. 控制条件，使事物向既定目标转化

关键提醒：
- **控制通常是限定在一个范围，而不是唯一结果。** 追求绝对确定会导致过度控制。
- 要考虑充足的可能性，警惕偏见和思维局限（只想到三种方案，不代表只有三种方案）
- 留**容错率**：容许一定的误差范围

## 2. 控制能力

> 控制能力 = 实行控制前的可能性空间 ÷ 实行控制后的可能性空间

这是一个可操作的量化思路。用它比较不同方案：哪个方案能把可能性空间压缩得更多，哪个控制能力更强。

反过来也成立：**如果一个动作没有缩小可能性空间，它就不是控制，只是动作。**

## 3. 四种控制方式（按效率从低到高）

**① 随机控制**（试错）
- 适用：一无所知、毫无规律的情形
- 特点：每次选择只有否定作用
- 陷阱：**必须确保目标在可能性空间内**，否则永远试不出来；避免错误地排除目标状态

**② 有记忆的控制**（排除已证伪项）
- 把"否定"升级为"排除"，不再重复试错
- 陷阱：**不可逆选择**。有些选项一旦尝试就再无机会，应先试可逆的；会削弱控制能力的选项不能最先尝试

**③ 共轭控制**（把不可控变成可控）
- 经典例证：曹冲称象。不能直接称象，就转换为称石头
- 结构：感受器（把对象转换成可控制的形式）→ 施加控制 → 效应器（转换回去）
- **工具的本质就是共轭控制**。语言、数字本身也是——把思想转换成符号，才能进行思维与交流
- 迁移：卡死时，不要加大力气，要**找一个变换**

**④ 负反馈调节**（持续逼近）
- 结构：出现目标差 → 产生减少目标差的反应 → 反复作用 → 逼近目标
- 特点：**控制效果可以累积**，控制能力不断增大
- 这是能力最强的控制方式
- 对比：保险丝、高压阀只是"半反馈"，不对调节效应做累积

**正反馈**：目标差不断扩大 → 恶性循环（军备竞赛、炸药爆炸、越焦虑越拖延）

## 4. 信息 = 知道 = 可能性空间的变化

"知道"就是**头脑中事物可能性空间变小**（有时也会变大，如纠偏、拓展认知）的过程。

- 信息量可量化：以 2 为底的负对数，单位比特，可叠加
- 信息和控制相互依存：**知与行的统一**。掌握足够信息才能控制，控制过程又产生新信息

**滤波：排除干扰的操作**
| 方法 | 适用场景 |
|---|---|
| 同一通道重复传递 | 排除随机、偶然干扰 |
| 不同通道传递同一信息再比对 | 排除系统性、规则性干扰（通道要尽量独立） |
| 阻抗滤波 | 保留信息、限制干扰通过 |
| 反馈滤波 | 用接收到的信息反作用于通道，抑制干扰 |
| 同步滤波 | 通道开关与信息同步 |

**信息与组织**：组织是建立联系、从无序走向有序的过程。系统必须获得一定量的信息才能组织起来，**组织度与信息量成正比**。

## 5. 黑箱认识论

这是本书最有当代价值的部分——它直接预言了机器学习的可解释性问题。

**基本设定**：认识活动 = 主体与客体之间的反馈耦合。
- 主体通过**可观察变量**（输出）认识客体
- 主体通过**可控制变量**（输入）改造客体
- 客体总有尚不可认知或不可控制的因素 → 所以它是**黑箱**

**两种方法**：
- **不打开黑箱**：通过输入输出建立模型。优点是不破坏原有结构
- **打开黑箱**：直接观察内部。但——

三个关键判断：
1. **打开黑箱只是打开了某一个层次**。摩尔根在孟德尔基础上观察基因，但染色体的工作原理又成了新黑箱。没有"彻底打开"。
2. **模型不必等价于黑箱内部的真实结构**。它是根据输入输出提出的假设。
3. **不打开黑箱并不比打开黑箱差**。研究地球结构不需要切开地球，研究疾病不一定要解剖有机体。

**何时该打开**：当打开的成本可接受、且打开后新增的可控变量价值显著时。

**认识论模式成立的条件**（五个，任一不满足就会失控）：
1. 可观察变量和可控制变量**受实践手段限制** → 手段要更新
2. 理论必须具有**清晰性和可证伪性** → 理论要给出信息量
3. 模型**逼近真理的速度**要超过**客体变化的速度** → 否则永远追不上
4. 避免**反馈过度** → 过度依据反馈修正，会把理论改得面目全非
5. **可判定条件**：实验误差要能反映理论与真理的接近程度。不成立时，只能用中间标准（范式、惯例）

## 6. 系统：稳态、演化与崩溃

**相对孤立系统**：忽略影响概率足够小的因素，把无限问题变成有限问题。关键是让内部因素尽量构成**互为因果的闭合网络**。

**系统变化的三种可能**：
1. 处于稳态结构（受扰后能自行回归）
2. 发生振荡或崩溃
3. 从一种稳态走向另一种稳态

**稳态结构**：多因素相互作用处于不变状态，一般干扰无法破坏，单独变动任一因素都很困难。
- 用途一：**预言**。找出全部稳定结构，最稳定的那个就是事物最可能趋向的目标（可跳过中间步骤直达结果）
- 用途二：**反向利用**。有时要特意规避稳态（挑选灵敏指南针、除杂草）

**超稳定系统**：用不稳定来维持稳定——出现偏离时启动修复装置复归。它是自稳定的，不依赖外力。

**周期性振荡**：不稳定作为稳定的补充。

**崩溃（自繁殖）**：内部形成因果关系的自动增长链，同时外部抑制的负反馈失灵。
- 共性：变量超过临界值 + 存在自动增长链 + 负反馈机制被破坏
- 例：核爆、激光、细菌繁殖、癌变、传染病流行

**自组织**：在一组事物间自动形成系统的过程。五个特点：
1. 先有一个**组织核心**
2. 系统处于不稳定或亚稳定状态
3. 存在有因果关系的**自动选择链**，可能性空间被限缩
4. 过程**不可逆**
5. 起始点的微小差别可导致结果的巨大差异

**智力放大**：把智力看作单位时间内做正确选择的能力，那么智力放大 = 选择能力的放大。手段是通过调节**组织核心**（包括组织他人），让整个选择过程自动放大。

## 7. 突变理论：质变是飞跃还是渐变

托姆的突变理论给出判据：**不看快慢，看中间过渡态是否稳定。**

- **飞跃**：中间过渡态**不稳定** → 必然中断，出现关节点
- **渐变**：中间过渡态**稳定** → 可以平稳过渡

**势函数模型**：
- 势函数的"洼"= 稳定态，洼越深越稳定
- 洼不变 → 状态稳定
- 洼移动变浅 → **渐变**
- 旧洼消失 → 状态经历不稳定态向新洼过渡 → **突变（飞跃）**

**三条极有用的推论：**

**① 关节点是一个区域，不是一个点。**
不要幻想找到"那个精确的临界点"。它在条件变化下规律分布，是一个区间。

**② 矫枉必须过正（滞后现象）。**
飞跃过程中，正向和反向的关节点不同（水要 100℃ 以上才沸腾，水蒸气要低于 100℃ 才冷凝）。**这是突变模型的固有属性，不是调错了。** 只有以飞跃方式质变时才存在滞后；绕开折叠区的渐变过程没有滞后。
- 迁移：改革、重构、切换方案时，出现"回不去、要多推一把"是正常的，别中途怀疑自己。

**③ 极端共存。**
在关节点分布区域内，彼此不连续的质态可以同时存在，而中间过渡态反而不稳定（岛上昆虫要么翅膀极强要么几乎没有，中间型被淘汰）。
- 迁移：在剧变期，中间路线可能最不稳定，不要默认"折中总是安全的"。

**飞跃 vs 渐变的条件**：
- 新质因素增强、旧质因素**没有明显减弱** → 飞跃（对抗激烈）
- 新质因素增强、旧质因素**明显减弱** → 渐变（此消彼长）
- 迁移：想平稳过渡，就要主动削弱旧结构，而不是只加强新结构

## 8. 迁移到具体任务

| 金观涛的概念 | 在 AI 任务中对应什么 |
|---|---|
| 可能性空间 | 先列出所有可能走向，再谈目标 |
| 控制能力 | 这个动作真的缩小了可能性空间吗 |
| 随机控制 | 完全陌生领域的试错，务必确认目标在范围内 |
| 有记忆控制 | 排除已证伪选项，注意不可逆选择最后试 |
| 共轭控制 | 卡死时找中间变换，而不是加大力气 |
| 负反馈 | 持续逼近、效果可累积（首选） |
| 正反馈 | 识别恶性循环并切断 |
| 信息 = 知道 | 每轮执行应该让不确定性下降 |
| 多通道比对 | 用独立路径交叉验证关键结论 |
| 黑箱认识论 | 看不透就用输入输出建模，不必强行打开 |
| 模型 ≠ 真实结构 | 模型只是假设，能预测就行，不必"正确" |
| 稳态结构 | 找最可能的终点，可跳过中间步骤 |
| 自繁殖崩溃 | 建立负反馈抑制，设上限 |
| 自组织与组织核心 | 找到关键杠杆点，小幅投入撬动整体 |
| 突变与关节点 | 重构/切换时接受滞后与矫枉过正 |
| 极端共存 | 剧变期中间路线可能最不稳 |

## 9. 本层的常见误用

- **把可能性空间列成愿望清单**：只写想要的结果，不写可能的失败
- **跳到负反馈而跳过共轭**：能找到变换时，共轭控制往往比反复试错高效得多
- **强行打开黑箱**：为了"搞清楚"而破坏系统原有稳态，代价超过收益
- **反馈过度**：每次用户反馈都全盘推翻方案，导致永远无法收敛
- **把渐变当成没进展**：在渐变模式下催促"飞跃"，反而破坏稳定性
