# L1 维纳层：系统、信息、反馈

来源：诺伯特·维纳《控制论——或动物与机器的控制和通信的科学》，1948 年初版，1961 年第二版。

## 核心主张

机器、生命体、社会，在"**控制与通信**"这一层上是同构的。区别不在材质（金属 vs 血肉），而在**是否具备通过反馈维持秩序的能力**。

这一步不谈怎么做事，只谈**怎么看待你要做的事**。

## 1. 系统观：先划边界

在维纳之前，"目的性行为"被认为是生命独有的。维纳证明：一个机械装置只要具备**测量偏差并据此修正**的回路，就表现出"朝向目标"的行为。老鹰捕猎不是预先算好弹道，而是每时每刻根据与目标的距离差调整。

**划边界的三个动作：**
1. **系统内 vs 系统外**：什么归你控制，什么是外部扰动。归错类是一切混乱的开始——把扰动当变量，会永远调不准；把变量当扰动，会白白放弃控制力。
2. **输入 / 状态 / 输出**：输入是你施加的，状态是系统当前的，输出是你能观测到的。三者混淆（尤其把输出当状态）是常见错误。
3. **耦合关系**：系统与外部环境如何互相影响。是否存在互为因果？

## 2. 信息观：信息即负熵

维纳的关键洞见，与申农并列：**信息是对不确定性的消除，在物理上表现为负熵。**

热力第二定律说孤立系统的熵（无序度）只增不减。生命之所以能维持秩序，是因为它持续从环境**汲取负熵**。对应到任务：

- 一个不被维护的系统，一定会自发走向混乱（文档腐化、代码腐化、计划失效）
- 维持秩序需要**持续输入信息**，一次性整理没有长期效果
- 因此：与其追求"一次做完美"，不如设计**持续注入信息的机制**（定期复盘、自动检查、例行同步）

## 3. 信号与噪声

维纳把通信问题放在与控制的同等位置，因为**控制依赖信息，而信息在传输中会被污染**。

三类干扰：
- **控制干扰**：发生在"我表达/施加"的环节（我没说清楚）
- **自然干扰（噪声）**：发生在传输通道中（信息在途中失真）
- **主观干扰**：发生在接收端（对方/模型理解偏了）

**滤波的四种基本手段**（维纳 + 金观涛共通）：
1. **重复传递**：同一信息走同一通道传多次 —— 只能排除随机干扰，排除不了系统性偏差
2. **多通道传递**：用不同路径传同一信息再比对 —— 能排除系统性偏差，前提是各通道尽量独立
3. **阻抗滤波**：在通道上加过滤器，只放有用的过（收音机选频）
4. **反馈滤波 / 同步滤波**：用接收到的信息反过来抑制通道，或让通道与信息同步开关

## 4. 通道容量：不多不少

维纳强调通道容量必须与信息量匹配：
- **容量太小**：信息丢失，接收方只能猜测，控制失效
- **容量太大**：引入额外噪声，且浪费成本

现实对应：给 AI 的上下文不是越多越好。塞满无关信息会降低信噪比，导致输出漂移。**给刚好够用的信息，比给全部信息更有效。**

## 5. 反馈观：负反馈与正反馈

- **负反馈**：偏差出现 → 产生减小偏差的动作 → 反复作用 → 逼近目标。这是**稳态**的来源，也是一切目的性行为的机制。
- **正反馈**：偏差出现 → 产生放大偏差的动作 → 失控。维纳把它与**病理**联系起来（震颤、恶性循环）。

判断自己在哪种回路里，是控制论思维最基本的动作。

## 6. 时间：预测与时滞

维纳花整章讨论时间序列与预测，因为**控制永远面向未来**。
- 完全确定的世界 → 一次算准，不需要反馈
- 完全随机的世界 → 预测无用，控制无意义
- 现实是**部分可预测**的 → 所以最优策略是**预测 + 持续修正**

**时滞是稳定性的头号杀手。** 任何反馈回路，如果测量和调整的延迟接近或超过系统自身的变化周期，纠偏就会变成加振——"我改的时候，情况已经变了"。

## 7. 维纳的人文关怀

《控制论》第八章写"信息、语言与社会"，他在《人有人的用处》(1950) 中进一步展开：当机器能替代人的信息传递功能时，**人的价值必须重新定义**。

这一点常被技术派忽略：**任何控制系统最终都作用于人**。设计回路时要问：这个回路是在增强人的判断，还是在替代并削弱它？

## 8. 迁移到具体任务

| 维纳的概念 | 在 AI 任务中对应什么 |
|---|---|
| 划系统边界 | 这个任务的输入、输出、不可控因素各是什么 |
| 信息即负熵 | 需要持续注入信息来维持，不能靠一次性整理 |
| 信号与噪声 | 上下文中哪些是信号，哪些是干扰，该滤掉什么 |
| 通道容量 | 给模型的上下文要恰到好处，不是越多越好 |
| 负反馈 | 每轮执行后测量偏差并纠正，而不是一次性投掷 |
| 正反馈 | 警惕"越改越糟"的放大回路 |
| 时滞 | 缩短反馈周期，避免基于过期信息纠偏 |
| 社会维度 | 最终作用于谁，是在增强人还是替代人 |

## 9. 本层的常见误用

- **把"系统"当成筐**：什么都往里装，边界无限扩大，等于没有边界
- **只谈信息不谈控制**：收集一堆信息却不做纠偏，信息就退化为噪音收藏
- **忽视时滞**：设计了一个理论上完美但反馈周期过长的回路
- **把正反馈当负反馈**：以为在纠偏，实际在放大（典型：反复重写导致偏离原意）
