# L3 钱学森层：建模、判稳、寻优、容错

来源：钱学森《工程控制论》(Engineering Cybernetics)，1954 英文初版，1958 中文版，1980 年宋健等修订版。

## 核心主张

维纳的《控制论》偏理论与哲学，工程师用不上。钱学森做的事是把控制论**从"解释世界"变成"设计系统"**：把工程实践中零散的设计原则和试验方法，取其共性，提高成科学理论。

**这一层全是动作。** 前面看清楚了、想清楚了，到这里必须能算、能判、能执行。

## 1. 建模：先有模型，再谈其他

钱学森全书从拉氏变换讲起，因为**没有模型就没有分析**。模型不需要精确，但必须能刻画"输入怎么变成输出"。

在 AI 任务中，模型通常是一张因果链：

```
输入 → [处理环节 1] → [处理环节 2] → ... → 输出
              ↑扰动        ↑扰动
```

建模的四问：
1. 输入量有哪些？哪些可控，哪些是扰动？
2. 输出量是什么？怎么观测？
3. 中间状态是什么？（往往是最容易漏掉的）
4. 各环节的代价是多少？（时间 / token / 金钱 / 风险）

**模型可以粗糙，但不能缺失。** 没有模型的执行，就是把输出交给运气。

## 2. 传递函数：因果链的增益

传递函数描述"输入经过系统后变成什么"。迁移过来就是问：**我做的这个动作，最终会放大还是衰减？**

- 某个环节的增益过大 → 微小输入导致剧烈输出 → 系统敏感、易振荡
- 某个环节的增益过小 → 动作没效果 → 需要加大投入或换路径
- 存在反向环节（负号）→ 那可能就是天然的负反馈，别破坏它

## 3. 频率响应：对不同节奏的敏感度

系统对**快变化**和**慢变化**的响应往往完全不同。钱学森用波德图、奈奎斯特图刻画这一点。

迁移：
- 对高频扰动的敏感度 → 系统是否容易被短期波动带偏
- 对低频扰动的响应 → 系统能否跟上长期趋势
- 如果只对高频敏感 → 会疲于应付，忽略大方向
- 如果只对低频敏感 → 反应迟钝，错过窗口

## 4. 判稳：这一步不能省

钱学森给出了一整套稳定性判据（奈奎斯特、根轨迹、劳斯判据等）。核心思想只有一句：

> **不稳定的系统，谈性能没有意义。**

在任务中的等价问法：
- 这个回路会收敛还是发散？
- 如果我按现在的纠偏力度持续调整，会逼近目标还是来回振荡？
- 误差在放大还是在缩小？

**三个典型的不稳定成因：**

| 成因 | 表现 | 处置 |
|---|---|---|
| 增益过大 | 纠偏过猛，来回过冲 | 减小单次纠偏幅度（降增益） |
| 时滞 | 改的时候情况已变 | 缩短反馈周期，或降低响应速度 |
| 噪声被当信号 | 把随机波动当偏差去纠 | 加滤波，多次观测取一致 |

## 5. 非线性：不要线性外推

钱学森用整章处理非线性系统与继电系统，因为**真实系统几乎都是非线性的**。

关键结论：
- 小范围内可以线性近似（所以小步试错有效）
- 大偏差下线性模型完全失效（所以不能把小规模验证的结论直接放大）
- 非线性会带来线性系统没有的现象：**极限环**（持续自激振荡）、**多稳态**、**跳变**

迁移：**在小样本上验证有效的做法，放大 10 倍后可能完全失效。** 规模变化时重新判稳。

## 6. 时滞：稳定性的头号杀手

钱学森专章讨论"有时滞的线性系统"，因为**时滞会直接把负反馈变成正反馈**。

- 反馈周期越短，系统越稳定
- 反馈周期接近系统自身变化周期时，纠偏变成加振
- 无法缩短时滞时，必须**降低纠偏速度**来换取稳定

迁移：把长任务切成短反馈。宁可多轮小幅纠偏，不要一轮憋个大招。

## 7. 采样：离散化与混叠

采样系统一章讲的是：以固定频率观测连续过程时，**采样频率不足会导致混叠**——看到的频率是假的。

迁移：
- 检查频率太低 → 漏掉中间过程，误判趋势
- 检查只在某些时刻进行 → 错过关键时刻的变化
- 采样点选择有偏 → 得到系统性错误的结论

## 8. 最优控制与自寻最优

同一个目标，存在多种控制策略，代价不同。**最优控制理论**研究如何以最小代价达标；**自寻最优**则更进一步：让系统自己去找最优点。

迁移：
- 先列出所有可行策略，再比代价，不要抓住第一个能用的就用
- 代价要算全：时间、token、风险、后续维护成本
- 自寻最优的现代形态：**让 AI 自己生成多个方案并评估**，而不是人先预设

## 9. 滤波：从噪声中提取信号

钱学森第 9 章（平稳随机输入）与第 16 章（噪声过滤）处理的是：**当输入混杂随机扰动时，如何设计系统仍能正确工作。**

迁移：
- 输入数据脏 → 先清洗再处理，或在环节中加入校验
- 观测到的偏差有随机成分 → 不要单次就纠偏，连续多次同向才动
- 多源信息不一致 → 交叉验证，取一致部分

## 10. 容错：用不可靠元件构造可靠系统

这是《工程控制论》最反直觉也最有价值的贡献。当时美国军方面临的问题是：元件不可靠，但系统必须可靠。

答案：**冗余 + 自检 + 容错设计。**
- **冗余**：关键路径留备份（人脑每天死大量细胞仍可靠工作）
- **自检**：定期诊断，发现故障并定位
- **纠错编码**：传输中自动发现并纠正错误
- **降级**：故障时切换到功能相近的部件，保住核心功能
- **功能自恢复**：系统能自动回到正常状态

迁移（长链路任务尤其重要）：
- 每一步都要假设它会失败
- 关键步骤设置**校验点**，不通过就不往下走
- 重要输出做**交叉验证**（另一条路径重做一遍比对）
- 准备**降级方案**：做不到 100 分时，60 分的版本长什么样

## 11. 自适应与自镇定

第 17 章"自行镇定和适应环境的系统"：当环境和任务变化时，系统能自动改变结构、参数，保持性能。

迁移：
- 环境变了，原来的参数还适用吗？
- 设计任务流程时，把"什么时候该重新校准"写进去
- 自适应不等于无限自适应——过度自适应等于没有基准

## 12. 迁移对照表

| 工程控制论概念 | 在 AI 任务中对应什么 |
|---|---|
| 建立数学模型 | 画出输入→处理→输出的因果链 |
| 传递函数 | 每个环节的增益与延迟 |
| 频率响应 | 对短期波动 vs 长期趋势的敏感度 |
| 稳定性判据 | 这个回路会收敛还是发散 |
| 非线性 | 小规模验证不能线性外推 |
| 时滞 | 反馈周期过长导致越改越糟 |
| 采样 | 检查频率是否足够、是否有偏 |
| 最优控制 | 多策略比选，算全代价 |
| 自寻最优 | 让模型自生成方案并评估 |
| 噪声过滤 | 多次观测取一致，多源交叉验证 |
| 容错与冗余 | 每步设校验点，关键输出交叉验证，备降级方案 |
| 自适应 | 环境变化时重新校准 |

## 13. 本层的常见误用

- **跳过判稳直接寻优**：在一个会发散的回路上调参数是自毁行为
- **把所有问题都建模**：建模有成本，简单问题直接做
- **过度冗余**：冗余消耗资源，只对关键路径冗余
- **把时滞当噪声**：这是两回事，处置方式完全不同（前者要缩短周期，后者要滤波）
