# 改造前安全验收单

> 任何写入、移动、重命名、删除或代码变更前逐项确认；存在未解决的高风险项时停止改造。

## A. 授权与范围

- [ ] 用户已批准《诊断报告 + 改造蓝图》
- [ ] 本次改造的文件、目录和外部系统范围明确
- [ ] 文档调整、代码变更、规则退休和删除项已分开列出
- [ ] 蓝图外新增动作已获得确认，或已从本次范围移除

## B. 备份与回滚

- [ ] 已创建目标 Skill 整目录备份
- [ ] 已生成文件哈希清单
- [ ] 已记录备份位置和恢复步骤
- [ ] 已确认备份中包含关键文件
- [ ] 已定义改造失败时的回滚标准

## C. 基线与测试

- [ ] 已记录改造前触发和任务基线
- [ ] 历史事故已形成回放用例
- [ ] 代码相关变更已有测试、快照或特征测试
- [ ] 已记录依赖版本、运行环境和必要命令
- [ ] 无法建立测试的部分已标注风险和限制

## D. 高风险确认

- [ ] 涉及权限、隐私、外部写入或数据处理的动作已确认
- [ ] 涉及安全、法律、合规或重大损失的动作已按关键风险管理
- [ ] 不可逆动作已有明确授权
- [ ] 脚本执行的网络、文件系统和账号范围明确
- [ ] 不存在未经请求的共享系统写入

## E. 执行准备

- [ ] 改造顺序明确，优先执行低风险结构调整
- [ ] 每一步都有验证方法
- [ ] 旧规则到新位置的映射表已准备
- [ ] 删除/退休项的审计记录已准备
- [ ] 用户知道备份位置和本次改造的主要风险
